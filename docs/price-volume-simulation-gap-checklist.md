# 量价仿真差距与验证清单

> **性质：** 活文档 / 后续检查清单，不是实现方案或已接受 ADR。
> **基线日期：** 2026-09-09。
> **适用范围：** 当前 A 股连续竞价游戏模型、NPC 策略、订单簿与量价观测。

## 1. 目的与判断原则

这份文档记录当前量价模型与真实市场之间仍可能存在的差距，避免后续只凭“走势看起来像不像”反复调参。
这里的“差距”不一定是 bug：有些是明确的游戏简化，有些需要数据校准，有些只有在扩展板块、公司事件或多人玩法时才值得实现。

后续检查遵循以下原则：

1. **价格和成交量必须来自同一权威订单簿的真实撮合。** 不为了画出预期曲线而补成交、改成交价或注入隐藏对手盘。
2. **先测量，再改策略。** 每项改动都先记录基线、多 seed 分布和假设，再比较改动后的统计特征。
3. **区分市场真相与画面采样。** UI 帧覆盖可以隐藏中间逐笔变化，但不得改变服务端 / WASM 引擎内的成交、日 K、持仓或资金。
4. **不把长期资金总量当作交易机制缺陷。** 总资金池增加、持平或减少是游戏经济设计选择；只需来源、去向和记账可解释，不要求机械守恒。
5. **不以某一条预画行情作为验收标准。** 验收对象是机制约束和统计分布，而不是“必须先跌、再放量反弹”的固定剧本。

优先级含义：`P0` 为 A 股语义或权威状态正确性，`P1` 为显著影响长期量价的核心缺口，`P2` 为重要真实性增强，`P3` 为扩展场景。

## 2. 当前已经具备的基线

以下能力已经存在，不应在后续方案中重复造一套：

- 玩家和 NPC 使用同一限价订单簿，价格优先、时间优先；成交量只在买卖委托实际撮合时产生。
- 默认 20,000 个散户、5 个机构、2 个游资均为独立账户，分别持有现金、库存、成本和 T+1 状态；
  客户端不传输 NPC 私有账户明细不改变服务端和存档中的逐户语义。
- 散户、机构、游资具有实例级参数、具名风格和独立随机注意力；价格波动、相对量能及盘口失衡会提高观察
  概率。稀疏候选 tick 和个体 RNG 进入权威存档，候选到期时按当前行情接受或拒绝，同 seed 可重放。
- `DriftUp` 机构使用权威市场 tick 计算估值漂移，不依赖无法随存档恢复的私有时钟。
- 散户具有追涨、抄底、止损、止盈反馈；机构按带个体偏差的隐藏价值分档试探和加仓；游资结合动量、相对量能与盘口失衡。
- NPC 工作报价会复用、撤换或日终失效，不会每 tick 无限制叠加同一观点的委托。
- 买入受到现金、整手和单股风险预算约束；卖出受到持仓及 T+1 可卖数量约束。
- 相对量能使用历史日量和日内 U 型累计进度作观测分母，但该曲线本身不制造成交。
- 前五档盘口失衡参与行为决策；行情快照与 UI 刷新已经和权威模拟推进解耦。

## 4. NPC 行为模型差距

| ID | 尚存差距 | 与真实市场的主要不同 | 可观察症状 | 优先级 |
|---|---|---|---|---|
| A01 | **三类身份与三类策略仍过于一一对应** | 现实中的散户也可能长期持有或看基本面，机构也会做动量、被动指数、止损和流动性交易；“身份”不等于单一策略。 | 同类账户之间收益、换手和方向相关性过高；某类 NPC 同时转向。 | P1 |
| A02 | **已有状态相关注意力，但仍缺少学习、退场和策略切换** | 当前价格波动、相对量能与盘口失衡会提高个体观察概率；现实参与者还会因长期盈亏、拥挤度和社会传播改变资金规模与策略风格。 | 活跃行情已有异步关注聚集，但运行数千天后失败策略仍不会缩小，成功策略也不会吸引资金。 | P1（注意力部分已完成） |
| A03 | **缺少公共信息、公司新闻、市场因子和行业联动** | 当前隐藏价值主要是逐股均值回复过程，难以产生财报跳变、系统性冲击、板块轮动和跨股票相关性。 | 股票间相关性过低；大跌 / 大涨多为单股自身订单流，缺少同步波动和波动状态切换。 | P1 |
| A04 | **组合决策仍以单股预算为主** | 现实资金会考虑总仓位、行业暴露、相关性、回撤、流动性与赎回压力，而不只是每只股票的资金上限。 | 机构在多只高度相关股票上同时满配；风险偏好不随总账户回撤改变。 | P2 |
| A05 | **缺少持续的母单与执行算法** | 大资金通常把目标数量拆成跨时段子单，并根据成交率、市场冲击和剩余时间调整；当前“分档下单”不等于有状态的母单执行。 | 订单方向持续性不足或过于规则化；大额需求的冲击不是随参与率和日均量平滑变化。 | P1 |
| A06 | **挂单价距、订单寿命和撤单机制仍较简单** | 真实订单的价距、寿命、撤单概率会随点差、队列、波动、订单流和不利选择改变。 | 点差、深度、成交率、撤单成交比和盘口恢复时间呈现离散台阶或不合理稳定。 | P1 |
| A07 | **行为参照点主要压缩为平均持仓成本和近期价格** | 现实参与者还会受分批买入价、前高前低、盈亏处置效应、新闻锚点、社交传播与注意力影响。 | 抄底、止损、止盈集中在少数阈值附近；行情缺乏逐步扩散和异步反应。 | P2 |
| A08 | **缺少被动资金、ETF / 指数调仓和套利型流量** | 这些订单可能不表达对单股价值的观点，却能形成收盘流量、跨股票联动和价格纠偏。 | 收盘附近缺少非方向性大额换手；相关证券之间的价差不能被修复。 | P3 |
| A09 | **独立自然人规模仍需向 10 万级压测** | 默认 2 万个散户已消除早期几十个账户代表整个市场的问题，但与大型 A 股活跃账户数量仍有差距；继续扩容会增加账户存档、日切结算和持仓遍历成本。 | 比较 2 万、5 万、10 万独立账户下的单户成交占比、无成交时长、存档体积和最快倍率。 | P1（2 万独立散户已完成） |
| A10 | **价格信号的时间尺度与一秒 tick 混在一起** | 当前 `history_len=20`，连续竞价每秒写入一次最新价；散户涨跌判断和游资默认 `lookback=20` 实际主要观察约 20 秒，而不是分钟、日内或跨日趋势。缓慢下跌半小时后即使累计跌幅很大，只要最后 20 秒横盘，抄底、恐慌和动量主体就可能看不到这段行情。 | 把“保留多少历史数据”和“某个 NPC 用多长周期判断”分开；为个体采样分钟级、日内和跨日窗口，按时间或分钟桶读取，不用 tick 数冒充时间。至少验证 30 分钟缓慢下跌、短促急跌、横盘后破位三种路径会产生不同信号；改变 tick 粒度或宿主倍速不得改变策略看到的市场时间跨度。 | P0 |
| A11 | **止损、止盈被短期涨跌方向和随机交易分支共同门控** | 当前散户只有短窗口下跌时才检查止损、上涨时才检查止盈，且先要通过到达概率和 `chase_prob` 分支。持仓已经越过个人风险阈值时，最近几十秒横盘或微反弹可能阻止止损；达到止盈线也可能长期不兑现。 | NPC 的候选观察到期后，先独立评估持仓风险，再评估追涨、抄底和噪音交易。止损 / 止盈是否执行仍由个人纪律、流动性、T+1 和随机犹豫决定，但不能依赖同一时刻的短期涨跌符号。验证“深亏后横盘”“深亏后微反弹”“盈利后横盘”及当日买入不可卖。 | P1 |
| A12 | **具名散户风格仍主要共用同一决策树** | 休眠、长线、噪声、抄底、动量和恐慌型目前主要通过阈值与概率改动同一组分支；例如抄底型仍可能走追涨路径。账户虽然独立，行为过程还缺少稳定的个体侧重点。 | 让风格决定候选行为集合和相对权重，并保留实例级参数；抄底型、动量型、恐慌型在相同市场路径上应呈现可测的不同响应分布。避免硬编码全体同步动作，也不引入代表性账户。 | P1 |
| A13 | **缺少个体关注集合及持仓优先观察** | 每次观察先从所有股票中均匀选择一只作为趋势和买入判断对象；只有进入噪声卖出分支后才会从可卖持仓中重选。该过程无法表达长期关注某只股票、持仓者更常查看持仓、买过后持续跟踪以及注意力逐渐转移。 | 为每个自然人保存小型独立关注集合；持仓、近期委托和异常波动影响选股权重，仍允许低概率发现其他股票。关注状态必须进入存档和 RNG 重放。比较持仓股与非持仓股的观察频率，并确保所有股票长期仍有被发现的概率。 | P1 |
| A14 | **订单数量与目标仓位及执行紧迫度联系不足** | 个体订单规模只从同类固定中心采样一次，风险预算主要负责截断买单。大库存账户仍可能长期每次只减两三手；机构的大额需求也没有明确的剩余目标数量，持仓规模不能自然转化为持续买卖压力。 | 先由独立账户根据财富、当前仓位、目标仓位、信号强度和风险形成目标增减量，再结合盘口、成交参与率与紧迫度拆成合法子单。订单仍受现金、库存、T+1、申报单位和板块上限约束。验收目标仓位收敛速度、订单方向持续性、冲击和成交率，不能直接制造成交。 | P1 |

### A09 的架构边界

2026-09-09 已明确否决代表性主体和批量生成匿名订单事件。扩容必须保持“一账户一参与者”：

- 每个散户都是独立自然人账户，现金、库存、成本、T+1、风格、注意力和随机状态均不可共享；
- 机构约 5 家、游资 1–2 个，各自账户独立且具有不同风格；
- 性能优化只能来自稀疏事件调度、数据布局、增量索引和客户端传输裁剪，不能改变主体语义；
- 2 万、5 万和 10 万规模测试必须同时核对逐户资产可追溯性与相同 seed 的可重放性。

当前已加入 20,007 个 NPC 的 release 压力门禁：按压缩为 300 tick、但保持每交易日期望观察
次数不变的完整交易日运行，核对同 seed 存档、JSON 往返恢复、逐户资产与注意力状态、日界以及
全局挂单上限拒单。2026-09-09 本机基线为 141.03 秒；这说明账户语义已经成立，但订单对齐路径
仍是明确的性能热点。5 万和 10 万规模尚未完成，仍属于后续任务，不得宣称已经验证。

## 6. 建议长期记录的指标

| 维度 | 指标 |
|---|---|
| 活跃度 | 日换手率、分钟成交量曲线、最长无成交时长、零成交股票占比、集合竞价 / 连续竞价成交占比 |
| 价格 | 日内与日间收益分布、尾部厚度、收益自相关、绝对收益 / 波动聚集、跳空分布、涨跌停频率与持续时间 |
| 订单簿 | 点差、前五档深度、盘口失衡持续性、订单寿命、撤单成交比、成交率、盘口被吃掉后的恢复时间 |
| 冲击 | 主动单数量相对近期成交量的价格冲击、冲击的非线性、买卖方向持续性及其衰减 |
| NPC | 各类换手、收益与回撤、现金 / 持仓集中度、长期闲置率、T+1 拒卖次数、单个账户成交占比 |
| 稳健性 | 跨 seed 分位数、不同 NPC 规模、WASM / Server / Tauri 一致性、不同倍速与发布频率下的权威结果一致性 |
| 性能 | 每 tick CPU 时间、每笔订单 / 成交成本、订单簿长度、快照序列化与发布开销、最快模式实际倍率 |

资金池只记录为经济观测项：总现金、证券市值、费用流向、外部注入 / 流出与财富集中度。它可以按游戏设计长期增加或减少，检查目标是**可解释和可对账**，不是强行保持不变。

### 2026-09-09 后续行为计划：持仓、行情背景与个人经历

> **状态：讨论方向已确认，作为后续 plan / checkpoint；以下机制尚未据此实现或验证。**
> 本节细化 A02、A03、A04、A07、A10–A14 的依赖关系，不替代已接受 ADR。
> 涉及策略架构、存档或契约的具体方案，实施前再形成相应设计 / ADR；所有行为阈值、
> 情绪更新和响应概率均为待校准的游戏假设，不是交易所规则或已证实的当前 A 股参数。

**目标：** 同样一段下跌，不同持仓、不同经历和不同判断的人，可以产生有理由的不同动作；
同一个人也会随自身处境变化而调整行为。价格与成交量继续只来自独立账户在共享订单簿中的撮合。

#### 机制与边界

1. **同时观察持仓损益、账户压力和利润回撤（A04 / A07 / A11）。**
   区分单股相对实际持仓成本的浮动盈亏、该股占总资产比例、账户整体损益 / 从资产高点的回撤，
   以及持仓曾有浮盈的回吐。成本 10 元与成本 6 元的持有人面对同一个 8 元，不应被视为同样亏损；
   轻仓与重仓也不应承受同样的账户压力。10%、20% 仅为可能的个人心理关口示例，不设为全体开关。
   风险在观察时独立评估，不等于越亏越必须卖：允许纪律止损、不愿认亏、等回本和摊低成本等不同倾向。
   买卖、费用及未来外部现金流会影响指标口径，实施前明确计算定义；补仓降低均价不得清除既有账户损失
   或心理经历，清仓后再买入的参照点重置规则也须显式定义。

2. **用多时间尺度表达行情路径（A10）。**
   个体可侧重分钟、日内、近数日、月度或半年 / 年度，也可同时判断“长期向上、短期危险”。
   观测至少区分累计涨跌、下跌持续时间、距前高 / 前低的位置、反弹强弱、量能和波动变化；
   不仅比较最新几秒的价格。窗口按市场时间 / 交易日定义，月份和年份对应的窗口口径须明确。
   已完成日 K 与当日截至当前时点的数据分开，禁止读取未来收盘或未来高低点。
   历史不足时显式记录可用长度与不可用信号，不伪造一年的行情，也不用默认趋势掩盖缺失。

3. **先观测市场，再由个人解释恐慌或乐观（A03 / A13）。**
   从权威行情计算不同窗口的市场组合涨跌、下跌股票占比、创新低占比及关注股票的共同走势；
   板块观测仅在存在明确行业分类时加入。游戏内市场组合须声明成分、权重、基期及无成交 / 陈旧价格
   的处理，不能冒充真实交易所指数。区分“少数权重股撑住指数”与“多数股票普涨”。
   公共观测可以共享，但关注集合、信息权重、观察时点和信念属于个人；散户不因此获得隐藏价值。
   恐慌可以提高卖出紧迫度，也可以使潜在买家撤单或观望；不能规定恐慌必然放量或必然成交。

4. **同一事实允许相反判断，风格是稳定倾向（A12）。**
   近期强势后的下跌，可以被理解为回调加仓，也可以被理解为见顶减仓。
   模型不能提前给所有人发“真正的底部 / 顶部”标签。个体风险偏好、趋势 / 反转偏好、
   信念坚持程度和观察周期相对稳定；经历改变其信心、风险承受意愿和行动权重。
   不要求所有人都使用同一决策树，也不靠每次重新随机性格来制造分歧。

5. **保留最小、可追溯的经历记忆（A02 / A07）。**
   允许表达“抄底后继续下跌 → 犹豫 → 账户压力加重且市场转弱 → 减仓 → 一段时间不敢买回”，
   也允许有人坚持持有直到接近回本才卖。变化由自身成交、损益和实际观察到的行情驱动，
   记忆更新、衰减、恢复和清仓后的保留范围须显式定义；不能把未成交意图记作已完成交易。
   不预设每个 NPC 都经历上述顺序，也不预设成功者永远加风险、失败者永远退场。
   第一阶段只保留足以解释这些差异的状态，复杂学习、社会传播和外部资金迁移后置。

6. **分开判断、目标仓位、执行与成交（A14 / A05）。**
   个人判断产生持有、观望、试买、加仓、减仓或退出意图，再结合财富、当前仓位与风险形成目标增减量，
   由紧迫度和流动性决定合法子单的价格、数量与持续性。看多不等于立即买，想买不等于有现金，
   想卖不等于当时可卖或能成交。现金、费用、冻结、库存、T+1 和已支持证券的申报规则仍由权威层校验；
   不为表达恐慌而绕过交易约束，不注入隐藏对手盘或现金。未来调整制度支持范围时须另查当日官方规则。

7. **决策可解释，状态可恢复（贯穿以上机制）。**
   行情特征可按股票 / 时间窗口共享计算，独立账户的成本、仓位、记忆、注意力和 RNG 不得合并。
   新增且影响后续行为的状态须进入权威存档；可推导缓存须可确定性重建。
   为离线诊断记录必要的观测窗口、盈亏参照、主要理由、目标仓位、执行受限原因与实际成交结果，
   区分“想卖”“已报单”“已成交”。解释从实际决策字段生成，不在事后编造心理独白；
   不要求把全体 NPC 私有明细传给客户端。诊断采样不得额外消耗策略 RNG 或改变结果。

#### 必须覆盖的对照场景

以下是测试设计方向，不预填未经校准的买卖比例或必然价格路径。行为测试可使用显式合成行情输入，
但完整会话验收不得往权威市场补写成交或价格。

| 对照场景 | 固定 / 改变什么 | 待验证的差异或约束 |
|---|---|---|
| 同价不同成本 | 同一行情，分别为浮亏、仍有浮盈的账户 | 个人盈亏参照不同；不能只按今日涨跌决定止损 / 止盈 |
| 同亏损率不同仓位 | 同一单股亏损率，分别轻仓、重仓 | 对整体账户的压力不同，风险敏感风格的目标仓位响应应体现差异 |
| 浮盈回吐与刚买入 | 当前成本收益率相近，但曾有浮盈和交易经历不同 | 保护利润或后悔等记忆机制能产生可解释差异 |
| 强势回调与持续阴跌 | 当日跌幅相同，过去数日 / 一月 / 更长历史不同 | 长短期信号不同，回调买入、退出和观望的分布可区分 |
| 个股下跌与市场共跌 | 个股路径不变，改变其他股票路径 | 市场风险敏感者响应改变；少数权重股强势不能掩盖多数股走弱 |
| 同一回落的不同解读 | 行情相同，改变个体倾向和持仓处境 | 可以同时有试买、加仓、减仓与观望，无统一顶底答案或全体同步动作 |
| 首次试买与连续受挫 | 当前市场和持仓条件相同，只改变真实经历记忆 | 相应风格的信心 / 紧迫度可不同；不是每次重抽性格 |
| 深亏横盘 / 微反弹 | 已越个人风险关口，短期不再下跌 | 仍评估风险，但由个人纪律与判断决定动作，不强制所有人卖出 |
| 补仓、清仓再入与历史不足 | 改变成本与持仓生命周期，提供短历史 | 不清除账户既有损失；参照点重置明确；无未来数据或虚构历史 |
| 意图受限与恐慌无承接 | 无可用现金、当日买入不可卖、缺少对手盘等 | 正确区分意图 / 委托 / 成交；允许零成交，不制造成交量 |
| 保存恢复及性能 | 同 seed 与命令，改变宿主、倍速、诊断开关并中途恢复 | 权威结果一致；逐户状态可追溯；报告新增状态和计算成本 |

依据：第 9 节的处置效应、有限注意力与分类学习研究用于支持参照点和信息解读的建模方向，
不能证明上述具体状态转移或参数已经符合当前 A 股；这些仍需第 5 节的敏感性分析与留出验证。

### 已落地的基线工具

引擎提供离线多 seed 报告，不读取墙钟，也不经过 UI / Publisher。先从游戏 UI 导出一个存档，工具只取其中的

```bash
cargo run -p engine --release --example price_volume_baseline -- stock-game-save.json 30 1,2,3,4,5
```

标准输出为 JSON，包含每个 seed、每只股票的成交活跃度、日内节奏、收益分布与尾部、量价相关、回撤、

可追溯极端样本。完整口径见 [`docs/diagnostics.md`](diagnostics.md)。seed 在 JSON 中使用十进制字符串，避免 JavaScript
读取大整数时丢失精度。参数、JSON 结构或其中的 `SessionSetup` 不合法时，工具显式失败并返回非零退出码；
工具不会读取或验证被忽略的存档快照、委托及账户状态。

## 8. 每项改动的完成检查

- 有一句可证伪的假设，例如“加入母单后，订单方向持续性上升，但单位成交量冲击不应线性爆炸”。
- 有改动前的多 seed 基线，而不是只保留一张截图。
- 有引擎单元测试、跨层契约测试，以及相关 A 股语义测试。
- 没有伪造成交、隐藏补贴、直接价格修正或为通过测试弱化断言。
- WASM、Server、Tauri 在相同 seed 和命令序列下保持权威结果一致。
- 快速模式只改变墙钟推进速度，不改变 tick 顺序、随机数消耗和交易结果。
- 文档明确标注：真实制度、经验校准、游戏简化，三者不能混写。

## 9. 依据与参考

### 现行制度（编码前须再次核对生效版本）

- [上海证券交易所交易规则（2026 年修订）及发布通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)：交易时段、开收盘集合竞价、申报与行情揭示；该页面同时明确部分条文继续暂缓实施。
- [上交所 2026 年规则附件 3：暂缓实施条文](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/10816482/files/f6bd756cdd8248f49b7795f62e73237f.docx)：编码市价申报等能力前，必须与规则正文及后续实施通知一并核对。
- [深圳证券交易所交易规则（2026 年修订）](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)：深市交易时段、竞价与申报规则。
- [深交所：市价申报方式说明](https://www.szse.cn/www/investor/knowledge/stock/deal/t20171120_538500.html)：对手方最优、本方最优、最优五档即时成交剩余撤销等类型。该说明发布日期较早，只用于理解类型；实现时仍以现行规则正文为准。

### 经验研究（用于提出校准指标，不等同于现行交易规则）

- [Lillo, *Order flow and price formation*](https://arxiv.org/abs/2105.00521)：订单流、市场冲击、母单拆分与执行算法综述。
- [Tóth et al., *Anomalous price impact and the critical nature of liquidity in financial markets*](https://arxiv.org/abs/1105.1694)：订单方向长记忆、拆分执行和非线性价格冲击。
- [Gu et al., *Stylized facts of price gaps in limit order books: Evidence from Chinese stocks*](https://arxiv.org/abs/1405.1247)：中国股票限价订单簿价差跳空的厚尾、相关性和个股差异。
- [Grinblatt & Han, *The Disposition Effect and Momentum*](https://www.nber.org/papers/w8734)：持仓参照价异质性、处置效应与动量之间的关系。
- [Peng & Xiong, *Investor Attention, Overconfidence and Category Learning*](https://www.nber.org/papers/w11400)：有限注意力、分类学习与跨资产联动。

这些研究的数据时期、市场结构和样本不同，不能直接把论文参数复制进游戏。它们适合用来定义“应当测什么”，实际参数仍需用目标时期、目标板块的 A 股数据校准。
