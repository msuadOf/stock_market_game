# ADR-0015：母单执行状态属于权威会话

- **状态：** 已接受（2026-09-10）
- **关联：** ADR-0005、ADR-0006；量价差距清单 A05、A06、A14

## 问题

机构或其他大资金的方向判断不应被直接等同为一张一次性限价单。目标数量、已成交数量、剩余数量、
价格上限、紧迫度和截止市场时间会影响后续子单；这些量若只放在策略对象中，读档后无法保证重放一致。

## 决定与当前边界

母单状态进入 `GameSession` 和 `SaveSlot`，按账户与股票唯一索引。当前仅 `ValueStrategy` 主动选择母单
执行；玩家、散户、游资仍保持原有逐笔意图语义。会话层把一个机构限价目标拆成至多一张带唯一订单 ID 的在途子单，按
剩余目标和距日终的市场分钟计算下一张的合法数量。策略在同方向的新判断可修订限价，不重置已成交量；
反向判断替换旧目标。

成交、撤单和日终失效只能经真实订单生命周期回写母单，绝不把未成交目标当作成交量。未完成目标日终
失效，不跨交易日带入旧观点。现金、库存、T+1、申报单位和阶段仍由权威订单路由层校验。

母单不承诺成交：无对手盘、价格限制、冻结或到期均保留为可诊断的执行结果。玩家不自动获得母单。

## 已验证

1. 一个 400 股机构目标先拆成 100 股子单；被接受或挂在盘口时已成交量保持 0；真实对手盘成交 100 股后才变为 100；
2. 部分成交后的母单状态可存档、恢复；存档校验拒绝非机构账户、未知股票、非整手、已满额、过期计划或活跃子单与订单簿不一致；
3. 子单仍由既有订单簿撮合，未引入直接成交或价格修正。

## 后续验收

1. 多 seed 下衡量订单方向持续性、参与率、冲击和成交率，校准拆分周期与数量；
2. 将订单寿命、撤单概率、盘口冲击建模推进 A06；
3. 为执行计划增加专门诊断，以区分目标、子单、撤单、到期和实际成交。

## 计划契约影响（2026-09-10）

`company-information-npc-intentions` 计划（用户已批准）K6 将母单演进为**个人交易
计划的执行子状态**，修订本 ADR 的下列边界（实施随 W4 任务，当前未实现）：

- **"当前仅 `ValueStrategy` 主动选择母单执行"——被取代：** 共同 V 与
  `ValueStrategy` 移除后（ADR-0016），母单语义并入 `TradingPlan` 的执行子状态；
  普通散户小单可复用同一执行协调器，不复制机构复杂度。每账户每股至多一个活跃
  子单；旧生命周期到期通过同一路由。
- **保持不变：** 成交、撤单和日终失效只能经真实订单生命周期回写；未完成目标
  日终失效不跨交易日带入旧观点；母单不承诺成交；现金、库存、T+1、申报单位和
  阶段仍由权威订单路由层校验。个人计划可跨日保留，但次日消息复核后才可能续发
  子单，不自动复活陈旧订单。
