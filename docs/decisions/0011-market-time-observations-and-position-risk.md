# ADR-0011：市场时间观测与持仓风险口径

- **状态：** accepted
- **日期：** 2026-09-09
- **决策者：** msuad
- **关联：** ADR-0005、ADR-0006、`docs/price-volume-simulation-gap-checklist.md` M01、A10、A11、B01

## 上下文

现有策略把 `history_len` 个逐 tick 最新价同时当作保留策略和观察窗口。默认连续竞价每 tick
代表一秒时，`history_len=20` 实际只覆盖约 20 秒；压缩测试日改变 `ticks_per_day` 后，相同的
点数又代表另一段市场时间。散户止损、止盈还位于追涨随机分支内部，并被最近价格方向门控。
这会让“缓慢下跌半小时后横盘”和“最近几十秒没有继续下跌”被误认为同一场景。

后续还需要把同一权威行情提供给 20,000 个独立自然人账户。公共行情特征可以只计算一次，
但账户成本、仓位、注意力、风格和经历仍必须逐户独立，不能借观测缓存把 NPC 合并成代表性主体。

本 ADR 只规定游戏行为模型的观测口径，不新增或解释交易所制度。窗口长度、风险阈值和响应概率
均是待校准的游戏假设。

制度口径于 2026-09-09 复核：[上交所《交易规则（2026 年修订）》第 2.4.2 条](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)
与[深交所《交易规则（2026 年修订）》第 2.3.2 条](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)
均规定股票 9:30–11:30、13:00–14:57 为连续竞价，14:57–15:00 为收盘集合竞价。因此下述
240 桶只能称为当前游戏的盘中时间轴，不能称为真实市场的 240 分钟连续竞价。

## 决策

### 1. 市场时间与运行速度分离

- 当前游戏日内时间轴固定为 240 个**盘中交易分钟桶**，午间休市不计入经过时间。M01 已以独立
  收盘集合竞价实现；连续竞价的权威 tick 仍映射到这 240 个游戏时间桶。因此这 240 个桶是获准的
  游戏时间轴，不是“现行 A 股有 240 分钟连续竞价”的制度陈述。
- Session 的连续竞价 tick 按当日连续竞价进度映射到 240 个交易分钟。一个 tick 跨过多个分钟
  边界时，这些已完成分钟沿用该 tick 完成时的权威最新价，表示期间没有新的价格观测；一个分钟
  内有多个 tick 时取跨越分钟末端的最后一个价格。`ticks_per_day` 可以改变价格更新采样密度，
  但不能改变窗口所声明的分钟数或令已完成分钟凭空缺失。
- 宿主倍速、Publisher 模式和 UI 刷新率只改变墙钟推进或观测交付，不能进入市场时间计算。
- 分钟序列使用 `(绝对交易分钟, 收盘快照价)`。没有成交的分钟仍记录当时权威最新成交价，明确
  表达陈旧价格；不能因为 UI 帧覆盖而漏掉市场分钟。
- 从原始 tick 批量生成分钟序列时，输入必须从当日连续竞价 tick 0 开始且逐 tick 连续；否则
  显式拒绝，禁止拿后一个样本向前回填未知行情。Session 增量路径直接按已完成分钟追加，不重建前缀。
- 读取窗口时必须命中所需的分钟端点；真实历史跨度不足或输入损坏时返回 `None` 并携带实际可用跨度，
  不用零涨跌或首个现存样本掩盖历史不足。

### 2. 具名窗口，不再由点数暗示语义

第一阶段公共只读观测包含：

- 1 交易分钟短期收益；
- 30 交易分钟慢趋势收益；
- 从权威活动日 K 的首笔真实成交开盘价至当前的日内收益；首分钟也必须包含集合竞价或开盘跳空。
  零成交活动日 K 的昨收占位不是开盘价，此时日内收益为不可用；
- 当前价相对前 30 个完整交易分钟高点、低点的位置，以及从窗口低点的反弹幅度；
- 相对 5、20、120、250 个**已完成交易日**收盘的收益。

当日观测只使用当前及过去的分钟桶与已经形成的活动日 K 开盘价；跨日观测只使用已经完成的日 K，
不读取未来收盘、高低点。完成日序号必须连续，缺日输入不得按数组长度冒充完整的 5/20 日窗口。
窗口结构同时报告实际可用分钟 / 交易日数。策略后续可以按个体风格选择或组合窗口，但不得把
`lookback=20` 重新解释为未注明单位的“20 个点”。

### 3. 游戏内市场组合

市场背景采用当前股票集合的**等权收益**与上涨、下跌、持平家数占比：

- 只纳入该窗口具有完整端点的股票；缺失股票不补零，并单独报告覆盖数 / 总数；
- 无可用股票时组合收益与涨跌占比均为 `None`；
- 这是游戏内等权市场观测，不冒充上证、深证或其他真实指数；在引入可审计流通市值与成分规则前
  不使用市值权重。

### 4. 持仓与账户风险

- 单股浮动盈亏率以该独立账户的权威平均持仓成本和当前权威最新价计算。无持仓或无合法成本时为
  `None`，不能按零成本推导。
- 单股仓位权重为该股当前市值 / 账户当前净值；账户净值为可用及冻结现金加全部持仓当前市值。
  输入价格、数量或算术溢出必须显式报错。
- 账户累计收益相对明确传入的账户参考净值计算；账户回撤相对明确传入的历史净值峰值计算。
- 持仓浮盈回吐相对明确传入的“持仓生命周期峰值价格”计算。该峰值属于未来 B03 的逐户权威状态；
  B01 允许缺失并返回 `None`，不得由当前短窗口高点冒充。
- B01 只建立只读值，不改变订单生成。B02 接入行为时，NPC 的一次观察被接受后，必须先评估所持
  股票风险，再评估追涨、抄底或噪声交易；是否行动仍受独立纪律、T+1、现金、库存和流动性约束。

### 5. 状态、缓存与重放

- 分钟收盘序列会影响后续行为，属于权威会话状态，必须随存档恢复并校验单调、唯一、正价格及
  合法长度。市场组合和收益等可推导结果不入存档，可从权威分钟序列、日 K 和账户状态确定性重建。
- 公共行情观测按股票 / tick 共享计算；逐户风险由账户自身快照计算。诊断开关不得消耗策略 RNG。
- WASM、server、Tauri 共用 engine 生成的观测；三宿主不得分别计算策略窗口。

## 不做

- 不在 B01 中调整 NPC 下单概率、方向、数量或报价。
- 不把无成交分钟删掉，也不注入成交来填充 K 线。
- 不用 UI 分时点或 Publisher 帧作为策略历史来源。
- 不增加代表性账户、共享持仓或批量匿名交易者。

## 后果

- 策略信号的单位可审计，慢跌、急跌和破位可以同时表达，且不依赖墙钟倍速。
- 压缩交易日把 tick 之间的市场分钟明确建模为最新价不变，不制造成交；窗口长度因此保持稳定，
  但粗采样本身仍会减少可出现的盘中价格路径细节。
- 每股最多保留当前行为所需的分钟桶与既有日 K，公共计算量与股票数相关，不与散户人数相乘；
  逐户账户风险仍保持独立。
- 存档契约会增加权威分钟历史，旧的 `price_history` 在策略完全迁移并完成兼容决策后才能删除。
