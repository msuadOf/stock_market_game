# ADR-0034：全部保留量价与交割历史，按日期分页查询

- 状态：accepted（用户已确认；代码及跨宿主验收待完成）
- 日期：2026-10-05
- 决策者：用户；AI 记录
- 关联：ADR-0023、ADR-0025、ADR-0030、ADR-0031、ADR-0033

## 保留范围

用户选择全部保留已结束交易日的分钟量价、日 K 和交易交割单，不采用“分钟仅保留最近五日”的裁剪方案。五日分时是查询和显示窗口，不是删除历史的条件。长期复盘依据真实已发生的成交与交割事实，不把日 K 推断为缺失的分钟成交，也不生成假逐笔。

日 K 的虚拟前史仍按 ADR-0023 明确标为生成数据；实时分钟和交割历史来自本局实际运行。该决定不要求生成本局尚不存在的开局前分钟成交，不授权保存历史盘口、未成交挂单或其他尚未讨论的资料类型。

## 日终持久化边界

日内新增事实仅在内存中累积，成功自然日日结后才将已结束交易日的历史与继续运行所需的状态一并提交。写入失败保持旧有效日终档和历史一致，不出现新市场状态配旧历史、重复追加或只写半批。休市证券不生成假分钟成交；正常零成交与缺少历史必须区分。

浏览器本地使用访问者的 IndexedDB；Server／Desktop 使用 SQLite；Remote 查询与保存都由 Server 负责，不运行本地 WASM 模拟或另存一份服务器档。不开启 WAL，不保存日内活动委托、待受理请求或更正队列。启动和明确换档加载一次，历史查询不得借机重新加载正在运行的市场。

## 查询与权限

历史接口按证券、日期范围及稳定游标分页，完整交割历史同时绑定授权本人的账户。用户可以逐页取完整范围，不通过静默截断或无解释上限丢弃事实。分页必须保持稳定排序，区分无成交、休市、未发生日期与不存在的历史；旧 generation／换档后的迟到结果不得安装到当前页面。

公开量价历史与私有交割单分开授权，不借历史查询泄露其他账户、挂单、现金、成交对手身份或 NPC 私有认识。交易所分别按本股真实开市日期组织历史，不用共享市场日数为休市证券制造数据。

继续遵守 Q02 的本人读取契约：NPC 本人决策实际读取历史才记本人读取经历，共享缓存生成和其他 NPC 读取不算本人经历；玩家显式请求成功取得历史也由统一访问层记账。历史查询不推进或重新加载市场，不意味着取消已确认的本人认知记账，缓存命中也不能替代真实调用者身份。

## 实施与不变边界

Engine 维护纯事实及查询契约，存储适配层负责数据库和文件 I/O。长期历史可以使用分层和分页避免每次读取全部内容，但冷热组织方式不能改变全部保留的决定，也不能以优化为由丢失或伪造数据。

仅接受当前代码契约，不增加存档版本、迁移、旧字段补齐或跨更新兼容。金额继续使用十进制分字符串，数量和日期口径在 Engine、宿主、存档、查询及 UI 中一致。具体 schema 与冷热索引的实施需短测试及非作者独立复核，不以本 ADR 宣称相关功能已完成。
