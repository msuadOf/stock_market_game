# ADR-0030：多人共享市场、入场资金与组合能力

- 状态：accepted（用户已确认产品规则；代码接线与验收仍待实施）
- 日期：2026-10-04
- 决策者：用户；AI记录
- 关联：ADR-0005、ADR-0024、ADR-0025、ADR-0027、ADR-0029

## 市场与玩家

多个已注册账号参与同一个市场，使用相同股票、盘口、时间与撮合状态，不为每个账号
暗中创建独立市场。初始化市场时向 NPC 分配股份；新玩家入场没有股份，只取得市场
设置指定的初始资金。默认100亿元，即10,000,000,000元、1,000,000,000,000分。

初始资金可通过市场设置修改，只影响之后的新入场玩家，不重置已有账户余额。
同一活动市场中的重复加入请求、重连与重新登录不重复发放资金。
首次入场初始化是明确的投资者外部资金来源，必须与撮合现金转移和费用流出区分；
它不是 NPC 补钱、税费返还或流动性保证，不把没有成交当成需要救市的故障。

## 接口与能力组合

市场控制与玩家账户/交易是独立接口与能力，不能以一个混杂的会话 token 默认授予
所有市场和账户权限。市场控制包含设置、暂停/倍速、新建/重置市场和加载日终存档；
这些操作改变整个市场而非仅改变某个玩家的视图，破坏性操作须明确告知全局影响。

创建市场的玩家默认组合市场控制能力与本人账户/交易能力；其他加入者默认只有本人
账户/交易能力。权限检查依据组合后的能力与资源范围，不把“管理员”写成不可扩展的
玩家类型，也不只靠 UI 隐藏按钮控制权限。交易账户从认证主体与市场成员关系解析，
不得通过改请求中的账号 ID 控制别人账户。

未来管理员效果通过组合市场控制能力实现；本决定不擅自规定完整角色管理界面、
能力转授策略、账号注册方式或数据库选型，这些具体接线另行讨论。

## 日终保存与加载

共享市场持久化仍只在成功自然日日结保存完整日级状态。日内只运行内存状态，不增加
WAL、持续 checkpoint 写盘或临时挂单存档；失败日结/写入保留上一份有效候选。
市场控制持有者可加载日终存档，所有玩家均切换至同一恢复后的市场时间线，旧请求和
旧异步响应不能落到新时间线；加载不是给每个玩家创建自己的市场副本。

登录身份独立于市场进度。已注册账号若不在被加载的旧存档中，提示重新加入，待本人
确认后发放一次该市场设置的初始资金，不自动加入、不删除登录账号、不静默恢复旧余额。
普通玩家不能通过本人账户/交易接口覆盖全局市场存档。

## 保持与待实施边界

保持 A 股 Money 分、股份股、T+1、费用、价格时间优先与实际受理规则。虚拟开局前史
及开局后真实撮合行情不变，不接真实市场行情；不做实时 GPU 或平台签名。
游戏存档只接受完整当前职责结构，不新增 schema_version 或格式兼容/迁移器。
金额跨端编码已由用户在实现审计 Q01 中选定为十进制分字符串，见
[ADR-0031](0031-money-decimal-cents-wire.md)；本决定不另设兼容格式。

本 ADR 登记已确认规则，不宣称账号、多人账户、数据库/云存档、组合授权及跨客户端
广播已经实现，也不把已有单玩家 SessionManager 视为多人市场验收通过。
