# ADR-0024：允许投资者资金池减少，不要求资金循环

- **状态：** accepted
- **用户确认日期：** 2026-09-30
- **记录日期：** 2026-10-01
- **决策者：** 用户确认；AI 记录
- **修订：** Q12、ADR-0006 与 ADR-0018 的长期资金循环待决要求；不改变现有交易制度。

## 上下文

Q12 原先把长期外部现金流作为待决问题。成交在投资者之间转移现金，佣金、过户费和
印花税按现有模型退出参与者账户，投资者现金总量可以逐渐减少。用户明确决定：
“资金不用有循环，资金池在一直变少市场也能正常运转。”

这里的资金池指投资者账户的现金总量，不是持仓市值、市场总市值或公司经营现金。
公司经营侧已有外部商业收付款，与向证券投资者补充现金不是一回事。

## 决策

1. 当前产品不要求资金循环、补充投资者现金或维持固定资金池规模。允许税费流出后
   投资者现金总量减少，不把这种减少本身认定为市场故障或未完成的经济模型。
2. 不为保持市场活跃而新增 NPC 收入、基金申赎、参与者进入退出、定期补钱、费用返还
   或资金重置机制。策略、宿主与性能优化不得偷偷制造现金或对手盘。
   多人市场中新玩家首次入场的设定初始资金按 [ADR-0030](0030-shared-market-player-capabilities.md)
   单独登记为外部资金来源；重复登录/重连不重复发放，不扩大为对已有投资者的补钱。
3. 正常运转指按实际资金、股份和现行交易约束处理请求与撮合，不承诺持续成交、
   固定成交量或永远有购买能力。缩量、缺少对手盘或零成交是合法结果，不伪造订单或成交。
4. 资金不足仍按既有语义处理：策略可以不提出订单，已提交请求按实际资金与费用校验；
   不豁免费用、不允许隐性透支、不自动缩小明确申报的数量。
5. 公司经营收付款、商业借款、还款、利息和税费继续独立记账；利润留存，不自动转入
   投资者账户。本发布不执行分红、增发、回购、股东清算分配及除权除息，既有边界不变。
6. Q12 按“不要求资金循环、不新增投资者外部现金流”核销，不再阻塞当前开发。
   未来若要引入上述资金流或公司行为，须另有用户决定与 ADR，不能从旧 Q12 推导实施授权。
   多人入场资金已取得独立用户决定，仅修订首次入场边界，原税费退出和不保证成交的规则保持。

## 备选方案与后果

- 按日补钱、返还税费或增加外部资金循环以维持交易量：当前不采纳，会引入用户不要求的
  经济行为并改变账户与费用语义。
- 保留现有现金转移与税费流出：采纳。长期流动性可以变化，不能据此声称市场统计已拟真，
  也不能保证任意长期情景都有成交。

## 实现与验证边界

原决策当批只更新产品决策、开放问题与关联文档，不改引擎、策略、费用、UI 或存档/API。
当批没有新增资金机制需要实现；现有规则测试仍须保留，当时仅做文档差异与本地链接检查，
不运行完整回归或长期市场验收，不以此证明任意长期负载与经济情景已通过验证。

ADR-0030后来确认的首次新玩家入场资金及共享市场尚待代码实现，本次文档修订不冒称
已有入场流水、账号持久化或多人守恒验收；其测试和完整回归必须以实际后续结果为准。
