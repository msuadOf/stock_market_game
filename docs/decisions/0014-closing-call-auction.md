# ADR-0014：收盘集合竞价使用显式交易阶段

- **状态：** 已接受（2026-09-10）
- **关联：** ADR-0009、ADR-0011、量价仿真检查 M01、C07

## 背景

沪深 A 股股票交易时段的 14:57–15:00 为收盘集合竞价，而不是连续竞价。此前游戏只建模开盘集合竞价，
使收盘价和尾盘成交的形成机制失真。

## 决策

`SessionSetup` 增加显式的 `closing_auction_ticks`，并新增 `TradingPhase::ClosingAuction`：

- 默认一秒一个权威 tick 时为 180 tick，对应 14:57–15:00；
- 该阶段只接受限价申报，撤单统一拒绝；
- 时段结束时复用按证券交易所选择的既有集合竞价清算规则；未成交余单在紧随其后的日界失效；
- `AuctionTick` 与 `AuctionCompleted` 均携带 `phase`，消费者不得按事件名称推断它一定是开盘竞价；
- 当前分时竞价可视区仍只显示开盘竞价；收盘竞价真实结果由权威日 K 收盘价传递，前端显式忽略其指示价，
  防止错误绘制到 09:15–09:25 区域。

## 后果

存档、Server、WASM 和 Tauri 都必须携带新的 setup 字段及事件阶段。后续要把收盘竞价画入独立尾盘区域时，
必须扩充分时坐标契约，而不能复用开盘竞价槽位。
