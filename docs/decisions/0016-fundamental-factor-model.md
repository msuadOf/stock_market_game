# ADR-0016：可重放的三层基本面因子

- **状态：** proposed
- **日期：** 2026-09-10
- **关联：** 量价差距清单 A03、C04

## 问题

逐股票独立的隐藏价值过程不能表达市场共同冲击、行业共振或单家公司事件。直接改写成交价或补造成交会破坏订单簿是唯一价格与成交量来源的约束。

## 拟议边界

1. 每只股票显式配置游戏内行业标签；标签不是交易所板块或真实指数声明。
2. 每个 tick 由 seed、权威 tick 和稳定标签派生市场、行业、公司三层冲击；不使用墙钟、不消耗策略 RNG，也不保存不可重建的私有时钟。
3. 三层冲击仅进入隐藏基本面价值的演化和可公开解释的事件观测。它们不直接写 `last_price`、日 K、账户余额或成交量。
4. 所有策略只能根据其既有权限读取公开事件；只有已获授权的价值策略继续读取隐藏 V。散户不会因该模型获得隐藏价值。
5. 行业配置、因子参数和事件状态一旦影响后续演化，必须进入 `SessionSetup`/`SaveSlot`，缺失或非法旧档显式拒绝。

## 验收

固定 seed 下，同一行业股票共享行业冲击、不同业不共享；公司冲击保持独立。禁用全部因子时保留现有 V 演化结果。改变宿主、刷新频率或存档恢复不得改变因子序列。任何价格变化仍须有对应订单簿成交事件。
