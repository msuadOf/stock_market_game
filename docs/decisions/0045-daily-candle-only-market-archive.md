# ADR-0045：历史行情只归档日K，分时仅保留在当前日内

- 状态：accepted（产品规则；跨宿主验收另记）
- 日期：2026-11-15
- 决策者：用户；AI 记录
- 取代 ADR-0034 的分钟保留决定；ADR-0034 的日期分页和本人交割权限规则仍然有效。

## 保留边界

当前交易日的分时点、集合竞价分时及分钟成交聚合是运行时数据。日结由权威引擎完成；成功形成日K及其成交量、成交额、成交笔数后，清空已结束日期的日内行情，即使观察者断开或不收包。日K进入日终持久化归档；本阶段已结算日期的分页查询仍使用已恢复到内存的日K索引，不从分钟事实重算。按需读取持久化归档留待后续。生成的虚拟前史日K不等于本局真实成交；不将日K反推为不存在的分钟成交。本人交割单、结算事实及恢复会话所需的状态不属于本 ADR 丢弃的行情数据。

同一公开历史 DTO 区分已成交、零成交、休市、开局前、尚未日结。已结算开市日必须带日K，成交状态以日K的真实成交量为准，不以不存在的分钟记录推测。休市、还未日结不生成归档日K；旧响应结构的 `bars` 字段固定为空。新日终档不含历史分钟；允许校验并读取旧档，不就地改写或清理已有文件和远端档案。

## 界面

共用行情界面取消五日分时与按自然日查询分钟成交。分钟周期仅显示当前交易日的真实成交，连续竞价按上午/下午分别聚合，集合竞价单独成柱。历史查询按日期分页获取日K并显示未归档、休市或零成交等状态；日、周、月、季、年 K 等由日尺度行情展示，不从分钟事实重建。数据延迟或失败不得显示成零成交。
