# ADR-0035：CompanySystem 共同入口与 SimpleFundamentals

- **状态：** accepted（设计）；实现和验证进度见[实施清单](../../agents/company-system/implementation-checklist.md)，不以本 ADR 宣称代码完成。
- **日期：** 2026-10-06。
- **依据：** 用户确认的[公司系统蓝图](../../agents/remaining-questions-and-features/q14-financial-model-design.md)，以及本轮“先接通 `company/simple`，`company/simulation` 后续另开分支”的决定。

## 问题

现有公司身份及 Session 装配强制依赖 `Books`、合同和完整经营状态。仅增加模式名称、隐藏财务明细，仍会让简单模式运行复杂仿真，也可能把没有的现金流当作零值用于估值或股东结算。

## 决定

`session → company` 通过薄共同入口 `CompanySystem` 调用。共同身份复用 `CompanyId`、`IndustryId`、发行人和股份数量；内部枚举只持有所选实现的状态。`CompanyKind` 的会计类别不等同证券板块。新局模式和配置必须明确，同局不切换；未实现的 `Simulation` 请求明确拒绝，不降级为 `Simple`。

本轮实现 `SimpleFundamentals`：共享轻量环境与公司独立趋势、扰动分别生成月度营收、固定开支及变动开支，再通过同期间收入、费用和所得税处理推导利润。不得另以净利率、目标利润或目标 ROE 覆盖结果；一项变动开支只能按营收比例或自身金额增长中的一种规则生成。零营收复业要求明确输入；比例超过 100% 可以表达亏损，不能任意截断。ROE 使用同期间、同范围的利润和平均权益，非正平均权益明确不可用，不将月 ROE 冒充年 ROE。

`Simple` 与后续 `Simulation` 提供相同上层财务查询、披露和股本行为契约，区别在内部过程的粒度，不是功能集合。简单模式可复用 `accounting` 的唯一账簿承接汇总事件，但不构造具体客户、工厂、研发项目或完整逐合同经营网络，也不在后台推进旧经营仿真。账面汇总收付、应收应付、资产和债务按明确规则形成相互勾稽的报表，同一项账面变化不得重复确认收入；月末不能覆盖已执行分红、认购或回购产生的现金和权益变化。材料标明 `SimpleGenerated` 来源、期间、范围和单位；解释来自实际生成步骤，不编造具体客户或研发经历。UI、NPC 和交易消费者使用共同契约，不按模式分叉财务功能。

用户进一步明确：简单模式只展示按上次结算及百分比规则生成的账面财务，不追踪真实公司资金流向，没有每月资金生成额度的概念。因此取消此前拟议的 `SyntheticFunding`、补款触发、额度与虚拟资本投入机制，不把这些问题视为待答或擅设默认。汇总报表仍需勾稽并明确标示模型来源，但不能把其现金或投资金额冒称已追踪的真实资金。

用户确认公司报表现金只作账面展示，不作为真实付款预算。简单模式分红校验可分配利润和方案等条件，但不因公司账面现金不足拒绝；投资者实际到账必须唯一且原子。配股和增发仍检查投资者本人现金，回购仍经真实委托与成交。不因查询、读档或技术重试重复发放，不给认购者补钱，不伪造成交。公司账面展示不构成投资者资金可任意覆盖的许可。此简单账面模型边界不扩展到 `Simulation` 的公司或客户。

用户批准明确标注为虚拟、可编辑且可按 seed 复现的默认参数预设。不使用真实市场统计，不根据证券价格倒推基本面；蓝图算例不自动成为默认数值。

公开排期复用既有 `ReportFrequency`，不在简单模型新增第二套独立披露时钟。公司内部生成事实与 `information` 的公开材料、账户本人获知分离；玩家只能查询已公开材料，NPC 只消费本人已获知材料。分析所需指标缺失时该方法明确不可用，不偷读私有状态、不静默更换方法、不制造共同正确股价。

推进使用既有自然日时钟和候选状态事务。失败不提交部分公司结果或随机状态；恢复保留继续运行所需事实。仅成功自然日日结通过现有宿主接口保存：浏览器 IndexedDB，Server／Desktop SQLite。当前存档严格校验模式、身份、日期和字段，不增加 schema 代际、旧格式兼容、迁移或默认补字段。

## 边界与后续

本决定不修改沪深证券撮合、T+1、交易日历或证券前史来源规则。简单账面财务属于明确的游戏简化，不声称真实公司经营、资金来源及偿付能力已经仿真。分红、送转、配股、增发和回购复用共同规则及结算能力，适用条件、登记时点、税务和失败原子性不因模式改变；需成交的回购不伪造卖方或成交。旧 ADR 中禁止股东结算的阶段范围已被用户的新要求取代，不能用于拒绝本轮功能。

`CompanySimulation` 的行业业务、有限客户现金和跨主体结算留到后续分支。既有独立会计算法与领域测试可保留，但不能为了保留测试而给简单 Session 加经营影子状态。共同入口及简单模式通过短单元测试和未实施者独立复核验收，不将此结果扩称为完整仿真或完整回归通过。
