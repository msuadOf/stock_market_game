# ADR-0013：散户最小经历记忆与可恢复关注集合

- **状态：** accepted
- **日期：** 2026-09-10
- **决策者：** msuad + Codex
- **关联：** ADR-0011、ADR-0012；量价差距清单 B03、A02、A07、A13。

## 决策

每名自然人散户拥有独立、权威且可存档恢复的经历状态：账户初始/峰值权益、连续失败买入数，以及每只已持有、真实成交过或真实观察过股票的最小记录。它不向普通客户端发布 NPC 私有明细。

只有两类事件能写入经历：

1. 已被引擎结算的实际成交；未成交委托、被拒绝委托和单纯的目标仓位不得伪装成成交。
2. 注意力调度实际接受后、策略已经审视的股票。未持仓观察只进入有限关注列表，不生成成本、入场或成交记录。

同一订单跨 tick 的部分成交使用订单 ID 去重：它可以更新持仓和成交时间，但不会重复把同一买入重置为新的失败尝试，也不会重复把同一盈利卖出当成多次信心恢复。补仓保留账户失败经历和个股峰值；清仓仅清除该股票的在场参照并启动 120 个游戏交易分钟冷静期，账户经历继续保留。关注列表永远保留持仓股票，额外最多保留 8 只最近观察/交易过的未持仓股票。

## 参数与边界

5% 买入后不利变动、120 分钟冷静期、连续失败后的重试概率和盈利卖出减一均为待校准的游戏行为假设，不是现行 A 股交易规则或经验事实。当前不设置时间衰减；后续校准若引入衰减，必须在此 ADR、存档迁移和固定输入测试中明确其时钟与边界。

存档将经历状态视为权威状态：散户账户集合必须完整匹配，价格、时间、持仓生命周期、峰值和冷静期均须一致。WASM 入站把 `retail_experience` 的账户键恢复为数值 `Map`；JSON、Tauri 与远程协议保持对象键。诊断读取派生聚合，不额外消耗策略 RNG。

## 后果

相同价格路径可因真实成交、失败和回撤形成不同的散户决策，同时仍保持每账户独立、同 seed 可重放和订单簿成交唯一来源。新增逐户状态会增加存档体积与观察成本，因此 B03 必须在 20,000 户压力门禁中报告其成本，且不能以代表性账户替代自然人账户。

可重复的本机测量命令为：

```bash
cargo test -p engine --release --test session twenty_thousand_retail_experience_cost_report -- --ignored --nocapture
```

它输出 20,000 个散户经历状态的 JSON 字节数、完整存档字节数、两者连续序列化的墙钟耗时，以及压缩为 300 tick 的完整游戏交易日推进耗时；耗时只作当前机器的该配置总成本基线，不表示经历功能相对于无经历版本的增量，也不进入权威模拟或确定性断言。

2026-09-10 本机 release 运行结果：经历 JSON `12,943,838` bytes，完整存档 `20,367,295` bytes；两者连续序列化 `73 ms`；压缩为 300 tick 的完整交易日推进 `2,827 ms`。这是本机基线，不可跨硬件直接比较。

## 计划契约影响（2026-09-10）

`company-information-npc-intentions` 计划（用户已批准）K5 在本 ADR 语义上做如下
修订，实施随该计划 W3/W4 任务执行（当前未实现）：

- **"当前不设置时间衰减"——被取代：** 引入每 20 个交易日无新受挫时失败影响
  减弱一档的显式衰减；衰减不是删除真实亏损，历史亏损事实保留。
- **新增经历状态：** 忍耐/信心/风险压力及失败事件日期进入逐户状态；日历时间
  与市场分钟分开记录（K1 双时钟）。
- **保持不变：** 5% 买入后不利变动的界定仍以成交后本人观察的不利变动确认，
  部分成交同订单去重；120 市场分钟冷静期保持；关注列表"持仓 + 8 只未持仓"
  上限保持；经历写入仍只允许真实成交与实际被接受的注意力两类事件。
- 待校准参数（重试概率、盈利卖出减一等）仍为游戏行为假设，不冒充经验事实。
