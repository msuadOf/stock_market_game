# ADR-0006: NPC 策略模块（Strategy trait + 每实例独立参数 + 可插拔扩展）

- **状态 (Status):** accepted（§5/§7 的隐藏 V 轨道与 `TrackV` 已被实现替代——见文末 2026-09-11 更新）
- **日期 (Date):** 2026-06-29
- **决策者 (Deciders):** msuad + Claude
- **解决：** [open-questions.md](../open-questions.md) Q11（NPC AI 行为模型）。
- **关联：** [ADR-0005](0005-unified-engine-three-deployments.md)（统一账户模型、撮合驱动价格）。

## 上下文 (Context)

ADR-0005 定调「统一账户 + 共享盘口 + 撮合驱动价格」后，NPC 是**主动挂单的 AI 参与者**，与玩家平权进同一 orderbook。但三类 NPC（散户 retail / 机构 inst / 游资 hot）各自的**下单策略算法**此前未定（open-questions Q11，阻塞 market/account 的 NPC 部分）。

研究（市场微观结构 + agent-based 模拟文献，见本 ADR §研究基础）结论：所有交易者都可抽象为「按策略决定下单意图」的函数，区别仅在策略类型与参数。两类奠基模型可对接到我们的三类 NPC：
- **零智力（Zero-Intelligence, ZI）模型**（Gode & Sunder / Cont-Stoikov-Talreja）：限价单、市价单、撤单按泊松到达率随机产生，不看信息。→ 散户噪音交易本体。
- **基本面 vs 趋势**（MDPI 2023）：期望收益 = 股息率 + 基本面项(价值-价格缺口) + 趋势项(动量偏好)。→ 机构(价值) / 游资(动量)本体。

msuad 2026-06-29 对策略模块给出明确要求：
1. **策略必须是独立模块**，与 account 解耦。
2. **每个 NPC 实例参数独立**（不同散户算法可不同、不同机构参数可不同）——同类内部也要有差异，市场才生动。
3. **后续要能插拔式添加更多策略**，不改现有代码（开闭原则）。
4. 采纳研究的三类映射：散户=ZI噪音、机构=价值、游资=动量。

msuad 2026-09-09 进一步明确：**一个 NPC 账户就是一个独立参与者，不能解释成代表性
资金群体。** 散户账户对应独立自然人，分别拥有现金、库存、持仓成本、T+1 可卖状态、
行为风格、注意力时钟与随机流；机构和游资也分别是独立账户。禁止用账户权重、合并库存或
批量订单事件替代这些账户语义。

此外 msuad 对「机构公允价」给出关键细化：**市场存在一个隐藏的「真实价值 V」轨道**（基本面随机游走，玩家不可见）；但**不同机构对 V 的「目标价/看法」可以不同**（可配置：固定目标价 / 跟随 V 带看法偏差 / 认为大致上涨）——即 V 是事实，机构的**预期**是各自参数。

## 决策 (Decision)

### §1 策略是 engine 内的独立模块

- 路径：`packages/engine/src/strategy/`（模块内可按策略拆文件：`mod.rs` + `trait.rs` + `zi_noise.rs` + `value.rs` + `momentum.rs`）。
- 不单独成 crate：策略是纯逻辑、与 orderbook/market/account 强耦合，TDD 同栈最顺；若日后逻辑膨胀再拆 crate（YAGNI）。

### §2 核心 trait：纯函数式决策

```rust
/// NPC 下单策略的统一抽象。看市场快照 + 自己的 RNG，返回一个「意图」。
/// 策略不直接碰 orderbook——只产 Intent，由 account/market 层执行。
/// 这让策略可单测、可插拔、可并行。
pub trait Strategy {
    fn decide(&mut self, ctx: &MarketView, rng: &mut Rng) -> Intent;
}
```

- `MarketView`：只读市场快照（当前盘口买卖档、近期价格序列、成交量、**隐藏公允价 V 仅对有权看它的策略可见**）。
- `Intent`：决策产物——枚举 `{ PlaceLimit{side, price, qty}, PlaceMarket{side, qty}, Cancel{order_id}, Pass }`。
- **RNG 由调用方注入**（呼应 ADR-0005 种子化 PRNG）→ 策略决策可重放、可断言（TDD）。

### §3 每实例独立参数（同类 NPC 内部也有差异）

- 每个策略 struct **自带参数**（如 `ZiNoiseStrategy { arrival_rate, order_size_mean, ... }`）。
- `GameConfig` 提供**分布参数**（均值/方差/范围），引擎为**每个 NPC 实例**采样出具体值 → 同类不同参数。例：两个散户的 `arrival_rate` 各自从 N(μ, σ²) 采样。
- 落实「不同散户算法不一样、不同机构参数不一样」的要求。

### §4 可插拔扩展（开闭原则）

- 加新策略 = 新增一个实现 `Strategy` 的 struct + 注册到「策略工厂」（`enum StrategyKind` + `fn build(kind, params, rng) -> Box<dyn Strategy>`）。
- **不改任何现有策略代码**。`Account` 持有 `Box<dyn Strategy>`（玩家为 `None`），对新策略透明。

### §5 隐藏公允价 V 轨道 + 机构各异的目标价

- 每只股票的 `MarketState` 持有一个**隐藏** `fundamental_value: Money`（基本面随机游走，玩家不可见；其随机性纳入 Session 的种子化 RNG）。
- 机构的「目标价」是**各实例参数**，三种可配策略（msuad 定）：
  - `Fixed(Money)`：固定目标价（机构对该公司有固定估值）。
  - `TrackV { bias: f64 }`：跟随 V，但带各自的看法偏差（bias）。
  - `DriftUp { rate: f64 }`：认为大致上涨（线性/指数漂移）。
- 同一个 V，不同机构看法不同 → 符合「不同机构看法不一样」。

### §6 玩家账户（不走 Strategy）

- `Account` 持 `strategy: Option<Box<dyn Strategy>>`。玩家为 `None`。
- 玩家下单：UI 动作直接构造 `Intent`（经请求通道注入），不经过策略 trait。
- 体现了「NPC=算法、玩家=外部驱动」的统一账户模型。

### §7 首批三策略（采纳研究映射）

| 策略 | 服务 NPC | 本体 | 关键参数（每实例采样） |
|------|---------|------|------------------------|
| `ZiNoiseStrategy` | 散货 retail | ZI 泊松 + 少量追涨杀跌 | arrival_rate λ、order_size_mean、trend_weight(小)、cancel_rate、holding_horizon(短) |
| `ValueStrategy` | 机构 inst（深度价值 / 成长 / 均衡 / 防御） | 基本面价值 + 拆单 | target_price_policy(Fixed/TrackV/DriftUp)、value_weight(高)、order_size_split(拆单)、holding_horizon(长)、fair_value_deviation(小) |
| `MomentumStrategy` | 游资 hot | 强趋势/动量 + 短线 | trend_weight(高)、lookback(趋势窗口)、order_size_mean、holding_horizon(极短)、cancel_rate(高) |

### §8 默认参与者人口与独立风格

- 默认创建 20,000 个独立散户、5 个独立机构和 2 个独立游资；客户端行情快照不携带 NPC
  私有账户明细，但服务端权威状态和存档逐户保留，前者是传输边界而不是账户聚合。
- 散户按实例固定为休眠、长线、噪声、抄底、动量或恐慌风格，并继续独立采样阈值。
- 默认五家机构按账户序号分配深度价值、成长、均衡、防御和积极交易风格；同风格内部仍有
  独立估值误差、风险上限和观察节奏。积极交易型机构保留机构账户身份，却使用动量策略族和
  普通工作报价，不读取隐藏 V、也不进入价值机构母单执行；策略族与账户身份因此不再强制一一对应。
- 默认两个游资分别采用动量和反转风格：前者放量顺势，后者在放量急跌时承接、急涨时兑现。
- 注意力用“每交易日期望观察次数”换算到逐 tick 概率，并用个体几何等待调度；这只减少
  没有观察事件的计算，不会合并账户或共享行为状态。
- `retail_cash_median` 是自然人初始现金分布的中位数。机构、游资仅按各自更高的账户尺度
  逐户采样，任何账户都不存在共享资金池。

## 研究基础 (Research Basis)

- **Winner Strategies in a Simulated Stock Market**（MDPI, Int. J. Financial Studies 2023）— 基本面/趋势双因子、参数 (cat, dur, tfp)、相对强度决定胜负。
- **Simulating Limit Order Book Models**（Watts）+ **Cont, Stoikov & Talreja (2010)** — 零智力泊松到达模型（限价/市价/撤单）。
- **Noise Traders**（NBER w12256）— 噪声交易者作为流动性与偏差来源。
- 详见上一轮研究记录（已纳入对话）。

## 备选方案 (Alternatives Considered)

- **A. 策略写成单独 crate** — 解耦更彻底，但当前与 engine 耦合紧密、TDD 跨 crate 更绕；YAGNI，待膨胀再拆。不选。
- **B. 三类 NPC 共用一套策略、仅参数不同** — 违背「不同散户算法可不同」（要能加新算法，非仅改参数）。不选。
- **C. 玩家也套 Strategy 外壳（HumanStrategy）** — 为统一性硬套一层无意义抽象；玩家本质是外部驱动。不选。
- **D. 无隐藏 V，机构退化为长线均值回复者** — 机构「价值判断」变弱、失去公允价依据；msuad 明确要隐藏 V。不选。

## 后果 (Consequences)

- **正面：**
  - 策略与账户解耦，account/market/orderbook 不依赖具体策略 → 可独立 TDD。
  - 每实例独立参数 + 可插拔 trait → 后续加策略零侵入，市场生动。
  - 隐藏 V + 机构各异目标价 → 机构行为有真实依据且多元化。
  - RNG 注入 → NPC 决策可重放、可精确单测（TDD）。
- **负面 / 代价：**
  - 多一个隐藏 `fundamental_value` 轨道（市场状态体积与复杂度↑），其随机游走参数需配。
- trait 对象（`Box<dyn Strategy>`）有动态分发开销；默认 20,007 个 NPC 依靠稀疏事件调度，
  只在个体观察事件到期时执行策略，而不是每 tick 扫描全部账户。
  - 三策略 + 分布参数 + 工厂是首批实打实的工作量。
- **后续需要做的：**
  - 解决 [open-questions.md](../open-questions.md) Q11（标已解决）。
  - 实现顺序（在 account/orderbook 之后或并行）：先 `Strategy` trait + `Intent` + `MarketView`，再三策略，再工厂。
  - `GameConfig` 扩展：每类 NPC 的分布参数 + 隐藏 V 的随机游走参数。
  - 后续每加一个新策略，补一个实现 + 单测 + 工厂注册项。

## 2026-09-09 行为细化：下跌中的价格发现

针对长期运行后出现“卖盘持续下移、最新成交价冻结、买盘消失”的现象，NPC 决策遵循以下边界：

- 不加入无限资金做市商，也不按日机械补充 NPC 现金；价格与成交量仍由同一共享订单簿内生形成。
- 最新成交价可能在无成交时陈旧。需要主动成交的策略以对手一档作为可成交报价：买方看卖一，
  卖方看买一；没有对手盘时才退回最新成交价挂单。
- 散户不读取隐藏公允价值。出现下跌趋势时，空仓者或尚未达到个人止损阈值的持仓者会把“跌了”
  误认为“便宜”，并在跌幅达到个人抄底阈值后用小单试探；只有亏损达到个人止损阈值且股份已经
  可卖时，才主动按买一止损。当日买入仍受 T+1 约束，不允许用策略绕过交易制度。
- 机构继续读取带个体偏差的隐藏价值，但比较对象改为卖一等可成交报价。报价刚进入低估区时仅使用
  计划单的四分之一试探，折价扩大后依次提高到二分之一和完整计划单；各档仍保持 100 股整数倍。
  若独立调用策略时传入的计划量不足一手，则放弃该笔买单，绝不静默放大委托量。
- 机构卖出同样不能产生任意非整手的部分委托：整手部分向下取整；账户存在可卖零股时，只允许
  在一笔委托中一次性带走全部可卖零股余量，与会话权威校验保持一致。
- `DriftUp` 估值策略的已运行时间只读取权威 `MarketView.market_minute`，不再维护未进入存档的
  策略私有计数器。相同存档市场分钟上重建策略与不中断运行的目标价判断必须一致，宿主 tick
  密度不会改变估值漂移的时间尺度。
- “下跌必然放量”不作为规则。缩量阴跌、恐慌放量、试探承接和反弹放量都应是买卖意愿重合后的
  结果，不通过价格动画或固定成交量制造。

本次细化改善订单的方向和进取性，但不承诺封闭经济在无限时间内永不耗尽现金。企业利润、分红、
税费去向和参与者收入属于资金循环模型，必须另行讨论并显式记账，不能伪装成 NPC 策略中的隐藏补贴。

### 个体阈值与量价反馈

经 2026-09-09 讨论确认，第一版价格—量能反馈采用“个体阈值 + 真实成交量”，不预设行情曲线：

- 每个散户在会话创建时确定自己的抄底阈值（1.5%–8%）、止损阈值（3%–12%）、止盈阈值
  （5%–18%）和追涨量能阈值（0.35–1.25 倍）；机构对隐藏价值的看法偏差为 -4%–+4%；
  游资追涨量能阈值为 0.5–1.5 倍。采样使用会话 RNG，同 seed 重建同一批性格。
- 配置中的散户、机构、游资订单数量是群体中心，不再是所有同类 NPC 的统一固定手数。每个实例
  在创建时从中心值的 60%–140% 区间采样一次，并落到 100 股整数倍；显式配置不足一手时不
  静默放大。这样减少成交量的同类尺寸格点，同时不增加运行期状态或改变 A 股申报单位。
- 跌幅加深时会依次击穿更多持仓者的止损阈值，同时也达到更多空仓者或尚未止损持仓者的抄底
  阈值。因此“多杀多”和“越跌承接者越多”可以同时存在，最终方向由共享订单簿中双方数量与
  报价决定。
- 反弹阶段，达到个人盈利阈值的持仓者主动向买一止盈；追涨者只有在真实量能达到个人确认阈值时
  才主动吃卖一，防止无量价格抖动让所有人同步追高。
- 相对量能由最近至多 20 个已经完成的日 K 平均成交量，与当日截至当前 tick 的权威成交量按日内
  进度比较得到。它是可重算的只读观测值，不写入存档，也不制造任何成交量。
- 前端默认群体扩大为 20,000 个独立散户、5 个独立机构、2 个独立游资，使自然人阈值分布
  有足够样本，同时保持机构和游资主体数量较少。

这是一套行为反馈机制，不是对“必然形成周期”或“无限期保持流动性”的硬编码保证。没有买卖意愿
重合时仍允许无成交；长期资金循环继续由未来的企业现金流、分红和参与者收入模型负责。

### 订单生命周期、风险预算与日内观测

经后续讨论确认，长期行情不能依靠每 tick 无限制追加固定手数委托：

- 每个 NPC 在实际观察点把工作报价与最新目标对齐：观点消失时撤单，报价变化时先撤旧单再报价，
  报价完全相同时复用原单；未到个体观察节奏时保持原单。集合竞价 09:15–09:20 可合法撤换，
  09:20 后保留原单且不再重复追加，不能为策略便利绕过不可撤单规则。玩家委托不受 NPC 工作
  报价策略限制。零智力散户的空结果（包括没有随机到达，或到达后没有可执行意图）均不产生新的
  撤单事件；机构和游资的空结果才代表持续扫描后观点消失。所有连续竞价委托仍按项目既定的当日
  有效语义在日终清簿并释放冻结。
- 买入量同时受决策可用现金、100 股申报单位和个人单股风险预算限制；决策可用现金扣除不可撤单
  冻结，但允许复用本轮会原子撤换的 NPC 工作单冻结额，避免相同观点因自己的冻结额反复撤挂。
  对齐后再按仍保留的真实冻结额对跨股票买单做一次累计整手预算，避免各股票重复使用同一份现金。
  散户单股上限从 15%–40% 采样，
  机构为 35%–75%，游资为 10%–30%。股票数量较少的测试局以等权重作为最低可行上限，避免单股
  游戏因“分散化”失去全部买方。账户层仍负责费用、冻结资金与 T+1 的最终权威校验。
- 固定观察间隔与相位已由“个体随机注意力”替代。配置首先表达每交易日期望观察次数，再依据
  `ticks_per_day` 换算成逐 tick 概率。首次候选观察时间由各 NPC 的独立随机流抽取，不在 tick 0
  强制全体同步。Session 以最小堆只唤醒候选到期 NPC，不在每个 tick 执行全部策略。
- 行情活跃度会提高、不会降低基础观察概率。活跃度取近期绝对涨跌（每 2% 为一档、最多三档）、
  超过 1 倍的相对量能（最多三档）与盘口绝对失衡（最多一档）三者最大值；散户、机构、游资的
  敏感系数分别为 0.75、0.40、1.25，有效概率上限为 1。该机制改变的是 NPC 何时看盘，不直接
  生成订单、成交量或价格。
- 为同时满足“使用候选队列”和“当前行情改变当前观察概率”，调度采用离散 thinning：每个 NPC
  按自身最大可能观察概率预排候选 tick；候选到期时才读取当时的 MarketView，并以
  `当前有效概率 / 最大概率` 决定是否真正观察。无论接受还是拒绝，都按最大概率安排下一候选。
  因此排队期间突然出现的暴跌、放量或盘口失衡会作用于下一个候选，而不会冻结为上一次观察时
  的市场状态；统计上等价于每 tick 以当时有效概率独立观察。
- `next_attention_candidate_tick`、基础概率及个体注意力 RNG 状态属于权威存档。注意力随机流与下单决策
  随机流分离；相同 seed、存档和玩家输入必须精确重放。候选几何等待使用逆分布一次采样，保留完整
  几何分布尾部，不再把低频自然人的等待时间截断在 10,000 tick。
- 抄底后的浮亏通过权威持仓成本和当前风险暴露反馈到下一次决策：浮亏越接近止损线，再次补仓所需
  跌幅越深；这比额外维护不可解释的“失败次数”更容易重放和审计。
- 相对量能不再假定全天线性成交。集合竞价占历史日量预期的 5%，连续竞价使用平滑 U 型累计曲线，
  反映开盘、尾盘较活跃的基准；这仍只是量能观测的分母，不会生成成交。
- 前五档盘口失衡进入行为反馈：卖盘明显更厚会降低持仓者的有效止损线、提高继续抄底所需跌幅，
  并阻止游资在严重偏空盘口中仅凭价格和成交量追涨。最终成交价仍只由共享订单簿撮合产生。

这些上限和日内曲线是游戏模型参数，不冒充交易所制度。长期外部资金循环仍未决定，记录在
[`open-questions.md`](../open-questions.md)，在形成显式资产负债来源前不得自动补钱。
