# ADR-0039：配股／增发／拆股的范围与新局开关

- **状态：** accepted（用户 2026-10-06 批准产品决策；实现归后续批次，不以本 ADR 宣称代码完成）
- **日期：** 2026-10-06。
- **决策者：** 用户拍板；AI 记录。
- **关联：** [ADR-0035](0035-company-system-simple-fundamentals.md)、[ADR-0037](0037-company-action-initiator.md)、[ADR-0040](0040-new-game-default-taxation-modes.md)；未定项见[当前交接](../../agents/company-system/current-handoff.md)「配股、增发……仍未完成」。

## 背景

[ADR-0035](0035-company-system-simple-fundamentals.md) 与[股东结算设计](../company-actions-design.md)已把分红、送转、配股、增发、回购列为 `Simple` 与 `Simulation` 的共同功能需求，但配股／增发的模式（面向全体股东还是定向）、参与主体的抽象方式、是否随新局启用均未敲定；[当前交接](../../agents/company-system/current-handoff.md)仍把配股、增发列为未完成。

用户 2026-10-06 拍板（原文）：「玩家和npc都是可以抽象成持有帐户的'用户'，公司增发/配股有定向，也有面向全体股东的，都要实现，还有拆股等也要实现。但是这样的配股/增发是可以通过创建一局游戏的时候通过选项来选择是否启用的。对于定向增发的意向由公司决定（这就涉及simple和抽象层的分界线了），可以分给持仓的机构股东，也可以公开配售，全市场都可以申购，也可以玩家来承购（价格先是默认市场价，接口可以变动价格，后续引入可以协商价格的机制，比如折价5%定向增发）」

## 决策

1. **玩家与 NPC 统一抽象为持账户的用户**：配股／增发／拆股的配售、认购与缴款一律按账户处理，不按「玩家 vs NPC」分叉功能（与 [ADR-0005](0005-unified-engine-three-deployments.md) 统一账户、[ADR-0030](0030-shared-market-player-capabilities.md) 共享市场能力一致）。
2. 配股／增发**两种模式都要实现**：「面向全体股东」（按登记日权益与持股面向全体股东）与「定向」（指定配售对象）。
3. **拆股等也要实现**：拆股纳入后续实现范围；拆股与缩股的方向、比例及登记处理须先按官方现行语义另行核验，实施批次不得凭印象实现。
4. **新局开关**：配股／增发可通过创建一局游戏时的选项选择是否启用。该选项属新局配置，同局不切换，严格持久化、恢复不改语义（沿用 ADR-0035 严格存档策略）；禁用后的具体形态（不生成方案还是显式拒绝请求）由实施批次另行明确。
5. **定向增发的意向由公司决定**（用户指出这涉及 Simple 与抽象层的分界线）：是否定向、定向给谁属公司侧决策，由 `CompanySystem` 共同层承担；`Simple` 经行为偏好（ADR-0037）形成意向，`Simulation` 的治理过程留待其分支。定向去向须支持：
   - 分给**持仓的机构股东**；
   - **公开配售**，全市场账户都可申购；
   - **玩家承购**。
6. **价格**：先按默认市场价；接口可以变动价格；后续再引入可协商价格的机制（如折价 5% 定向增发），本轮不实现，仅保持价格参数可扩展。
7. 认购仍检查投资者本人真实现金，不补认购资金（ADR-0035 既有约束）；发行人侧收款在 `Simple` 下按账面事实处理、不追踪真实公司资金流向，`Simulation` 须走真实资金链。

## 备选方案

- 只实现面向全体股东的配股／增发：拒绝。用户明确「有定向，也有面向全体股东的，都要实现」。
- 定向名单由宿主或测试脚本逐笔指定：仅保留为显式 API 的测试／特殊场景路径（ADR-0037），正常游玩的定向意向必须由公司侧决定。

## 后果

- **正面：** 参与主体按账户统一，配售对象三类去向覆盖机构股东、全市场与玩家；新局开关让不想要股权再融资的局可以显式关闭。
- **负面：** 新局配置、严格存档契约与 UI 须同时承载启用开关与定向模式；拆股依赖官方语义核验，未核验前不能实现。
- **后续批次：** B4（配股／增发批次）scope 据此确定——两种模式、公司侧意向决策、默认市场价与可变价格接口；协商定价不实现、只留扩展点。新局「启用／禁用配股／增发」选项与税务模式选项（ADR-0040）共用 B2 的新局选项配置与 UI 入口，B2 的配置面须一并承载。拆股在官方语义核验后另行安排批次。
