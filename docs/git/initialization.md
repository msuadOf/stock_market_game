# Git 初始化与接管指令

当你首次接管仓库，或发现 Git 身份/仓库配置尚未就绪时，按本文件执行。

1. 确认当前工作目录是否为 Git 仓库。若不是，先检查该目录确实是用户正在操作的项目；确认后可执行 `git init`。
2. 检查当前分支、远端配置、Git 用户名和邮箱、以及未提交修改；不得假定仓库、远端或身份配置存在。
3. 若 Git 用户名或邮箱缺失，向用户询问希望使用的姓名和邮箱。优先仅为当前仓库写入本地配置；不得修改全局 Git 配置或编造身份信息。
4. 列出已有未提交修改，并将它们视为用户或其他协作者的工作。不要重置、清理、覆盖、暂存或提交这些修改。
5. 在用户的后续实质性修改开始前，若当前位于 `main`、`master` 等受保护分支，按项目约定创建合适的工作分支；若已在合适的工作分支，则继续使用它。

完成后，以非技术语言报告：仓库是否就绪、是否存在尚未保存的本地工作、还缺少什么信息，以及哪些对外/破坏性操作会先征求确认。初始化不得包含上传或创建任何远端资源。
