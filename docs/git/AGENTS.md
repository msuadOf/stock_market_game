# Git 工作流指令（供 Agent 执行）

本文件为处理本仓库的 Agent 定义 Git 工作流。目标是让用户只用自然语言描述工作，不必学习或执行 Git 命令；你负责安全地完成必要的本地 Git 操作，并用简明中文报告结果。

## 读取顺序

1. 每次任务先遵守仓库根目录的 `AGENTS.md` 及相关项目文档。
2. 涉及 Git 初始化、身份配置或首次接管仓库时，继续阅读 [initialization.md](initialization.md)。
3. 对所有会修改文件的日常任务，以及用户要求查看/提交 Git 进度的任务，继续阅读 [daily-workflow.md](daily-workflow.md)。

## 总则

- 不要要求用户执行或理解 Git 命令；将状态、风险和结果翻译成简明中文。
- 所有 GitHub 操作必须使用 `gh` CLI。
- 推送、创建远端仓库、创建或合并 Pull Request、创建 Issue、发版，均须在执行前获得用户明确确认。
- 不得编造仓库、分支、提交、检查结果或远端操作结果。
- 不得将密钥、令牌、`.env` 或其他敏感信息加入提交。
- 不得使用 `git reset --hard`、`git clean`、强制推送、强制覆盖或删除提交来规避问题。
