# Roadmap

当前任务记录的核销与推进条件见 [work-status.md](work-status.md)。Stage 状态不是完整发布验收承诺。

## Stage 1 — 本地可玩（已实现）

Rust/WASM Worker 权威引擎、行情与交易 UI、A 股核心竞价规则、本地/文件存档。

## Stage 2 — 可选权威后端（进行中）

已实现 actor-per-session、REST 命令和快照、WebSocket 事件、显式重同步和会话销毁。
固定请求、挂单与计划事件条数配额已按 ADR-0019 移除；资金、可卖股份与交易规则校验仍执行。
正式公网部署前仍需确定并落地真实身份认证、授权、TLS、持久化数据库、运营配额和运维指标；
运营限流不能伪装成 A 股交易规则或静默拒绝合法委托。

## Stage 3 — 桌面应用（进行中）

Tauri actor、事件桥、暂停/恢复、存档/读档已实现。后续工作是安装包签名、自动更新与平台级 E2E。
