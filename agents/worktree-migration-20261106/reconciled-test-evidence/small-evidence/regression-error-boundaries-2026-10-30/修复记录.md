# 回归边界用例修复记录

本记录对应 2026-10-30 独占 worktree 中的三项测试夹具调整，不修改生产逻辑或 A 股交易规则。

## 范围

- `read_only_start.rs`：移除通过清空 `setup.stocks` 制造 context 错误的夹具。该操作破坏 Calendar 绑定，会让新 Calendar 入口先 panic。现用零昨收让 `up_stop` 在 `AccountValidationContext` 阶段返回明确错误；hydration 名义费用反例保持原样，资源错误优先级和业务状态哈希断言保留。
- `continuous_matching_adapter_tests.rs`：跨股 map 错误夹具保留两个 `StockId` 键，交换两只 `Market` 的值，并精确断言 map key 与 market stock code 不一致的 typed error。
- `continuous_tick_finalizer_tests.rs`：先直接捕获并精确检查 `PhasePolicy::boundary` 的 tick/day overflow 错误，再断言 `prepare_market_tick` 返回的 fatal 与 `prepare_market_calendar_tick` 的错误完全相等；原回滚哈希及 `u64::MAX` tick 断言保留。
