# wait primitives 边界补证

## 范围与合同

仅修改 `packages/engine/tests/wasm_wait_primitives.rs`，生产代码未改。以 main `b8263100` 与旧 `a1069614` 的测试差异、当前 `src/runtime/wasm_wait.rs` 合同为依据；已读 AGENTS、principles、testing、architecture、open-questions 与 ADR-0043。纯等待机制不涉及交易所、板块、证券类别、A 股交易单位或交易制度变化，无需引入新的交易规则依据。

新增 8 个代表性短 case：zero deadline 对 buffered/empty/disconnected 的首次轮询；exact deadline 后消息保留；coordinator 高于 start 的回退、worker spin/quiet 内回退；coordinator/worker 在消息返回前 host abort 二次检查；worker 消息返回前 shutdown 二次检查。复用 FakeRuntime 增加有限 clock 样本与 host 检查注入，无新依赖。

main `src/runtime/watchdog_wait_verification.rs::verify_wait_boundary` modes 4/5/6 已有 bare recv 消息、shutdown sentinel、host abort 选路与返回检查，故没有再复制旧分支的 native bare suite。该已有覆盖属于 WASM verification 入口，本轮未运行浏览器，不以它的存在冒充本轮验收成功；也不声称已观测私有 futex park。

## 验证

这是补既有实现的合同证据，未修改实现、未伪造红灯。`git diff --check` 通过。

Cargo 构建：`node scripts/run-long-validation.mjs 300000 -- cargo test -p engine --test wasm_wait_primitives --features verification-harness --no-run -j16 --message-format=json`，日志为 `build.jsonl` / `build.stderr`。运行中观察 Cargo 在 registry index/crate 文件读取处处于 `folio_wait_bit_common`、`wait_on_buffer`、`rq_qos_wait`，未进入 rustc；CPU 约 0.2%~0.4%，属于磁盘 I/O 等待，非可并行计算故意串行。

独立构建：`node scripts/run-long-validation.mjs 300000 -- rustc --edition=2021 --test packages/engine/tests/wasm_wait_primitives.rs -C codegen-units=16 -o agents/worktree-reinspection-20261104/wait-boundaries/wasm_wait_primitives-direct`。编译成功，日志 `direct-build.log`；实测 rustc 有 4 个线程。测试文件仅依赖 std 且以 path 引入真实生产模块，此构建不依赖 engine 全 crate，也不等价于 Cargo workspace 验收。

独立执行：`node scripts/run-with-deadline.mjs 10000 -- agents/worktree-reinspection-20261104/wait-boundaries/wasm_wait_primitives-direct --test-threads=16`。17/17 通过，0 ignored，harness 报告 0.00s，整条监督命令 0.13s。整套受 10 秒外部硬门禁，因此各 case 同样无法超过 10 秒。日志 `direct-tests.log`。

未运行完整 engine/workspace 回归或浏览器验证。待独立 reviewer 审查完整 diff 后才能宣称本批完成。

Cargo 最终失败：监督器在约 299899ms 耗尽执行预算，exit 1；接近期限时才进入 engine 编译。监督器确认 direct child close，但报告 `process tree termination remains unconfirmed: owned process group identity unavailable after root exit: 2721662`，因此不能报告其清理门禁成功。随后独立进程表核对未见该 process group 或其 rustc 遗留；这不是放宽 deadline 或抹去原始门禁失败。
