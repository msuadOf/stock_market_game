## Option 谓词三值核对

原拒绝条件均为 `!option.is_some_and(P)`，改写为 `option.is_none_or(!P)`。`None` 时两个表达式都为真；`Some(合法)` 即 P 为真时两个表达式都为假；`Some(非法)` 即 P 为假时两个表达式都为真。

| 位置与 P | None：原/新 | Some 合法：原/新 | Some 非法：原/新 |
|---|---:|---:|---:|
| `inventory_sources.rs`：库存项账户等于来源账户 | 真 / 真 | 假 / 假 | 真 / 真 |
| `player_company_command_candidates.rs`：持仓数量大于 0 | 真 / 真 | 假 / 假 | 真 / 真 |

特别核查：新式中 `is_none_or` 前不保留外层 `!`。若保留，真值会反转。这是本次复核修正的关键点。

`cash_dividend.rs` 的 `registered != !matches!(status, ...)` 改成 `registered == matches!(status, ...)`，由布尔等价式 `a != !b == a == b` 得出，状态校验结果不变。
