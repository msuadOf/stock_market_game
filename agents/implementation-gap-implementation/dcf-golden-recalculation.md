# DCF 金样独立重算

G06 已将每年现金流各自折现到第 0 年，但此前只更新了 `gold.rs`，`priors.rs` 与筹资路径的旧金样仍使用错误折现结果。本轮定向 fundamental 短测发现三处失败，不能删除断言、只检查方向或直接把实际输出抄为期望值。

独立计算器 `dcf-golden-recalculation.mjs` 不导入 Rust 或产品模块，仅按固定 K5a 数学契约及夹具年度现金事实，用 BigInt 与独立半偶有理数运算逐年推导。初始 FCFE 为 FY2029 的 16,200,000 分、FY2028 的 7,200,000 分及 FY2030 的 17,820,000 分；资本成本 1000bp、终值增长 0，增长分别为 3000、2500、-3000、-2000、0bp。真实付息例由 1,000,000 分经营现金减 50,000 分利息得到 950,000 分。

计算器先固定正负半单元半偶例，再输出完整未来现金流、逐年现值和终值。运行 `timeout 10s node agents/implementation-gap-implementation/dcf-golden-recalculation.mjs` 约 0.03 秒完成；这是独立数学重算，不是游戏回归。只更新被 G06 正确公式改变的金样数值，保留相反修订、材料来源、增长、信心、字节稳定、费用和不可用负控全部断言。最终产品短测及非作者数值复核结果待核收。
