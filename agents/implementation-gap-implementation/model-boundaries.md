# 估值、经营及公开输入边界

本组沿用审计的现行契约，分别修复 G06、G15、G54、G70、G74、G77。每个独立缺口分别提交产品代码和对应测试，不混成一个产品提交；本记录集中保留同组验证依据，不替代原需求文档。

## 实现与独立推导

| 项目 | 实现及保留边界 |
|---|---|
| G06 | 每期 FCFE 逐年增长后折现该期年数，终值仍按5年折现，均逐步整数半偶到分。恒定 FCFE=17,820,000分、g=0、r=1000bp、gt=0，五期PV为16,200,000、14,727,273、13,388,430、12,171,300、11,064,818分，终值PV=110,648,179分，合计178,200,000分；独立BigInt重算悲观131,444,507与乐观253,208,693分。原gold一次折现预期有误，按独立逐期推导修正，不放宽断言。 |
| G15 | 同交易所/年度存在Official覆盖时，未落入覆盖休市区间的工作日为Trading，不再叠加模拟假日；周末仍休市。无覆盖的交易所/年度仍fallback。只有合成出处Fixture，不新增真实休市表或行情。 |
| G54 | Money::from_yuan_str拒绝只有小数点或符号加小数点；保留.5、12.、+.0、-.1等至少含一位数字的既有接受集合。 |
| G70 | 工商开局库存种子对账补入工业报表同真源的1403/1405/5001，已存在但没有seed的科目按零子账余额核对；custom chart没有该科目时不要求凭空添加，其他实际seed科目仍核对。 |
| G74 | Continuous和Auction的P3身份预检错误调用既有fail锁存，拒绝后续next_ready_batch与finish；不改正常撮合或全局调度顺序。 |
| G77 | 非正内部往来声明显式拒绝并携成员、对手方与金额；真实正额AR/AP100元仍生成1条底稿，不写回成员账套。不因此核销G28集团接线及金额账面上界。 |

## 定向短测

构建使用专用 `.tmp/gap-target`，`cargo test --no-run -j 16`，包括上述涉及的五个integration binary和engine lib binary，仅编译不执行全套。

各binary分别用 `RAYON_NUM_THREADS=8 timeout 10s <binary> audit_boundary_ --test-threads=8`，绿测六个binary并发执行；另单独执行真实披露到个人信念的 `gold::cash_flow_end_to_end_gold --exact`。

| 验证 | 旧码红测 | 修复后绿测 |
|---|---|---|
| G54 Money新case | 无数字输入被接受，失败 | 1通过，0.00s |
| G15年度覆盖新case | 元旦叠加模拟休市，失败 | 1通过，0.01s |
| G06逐年PV新case | 191,648,179≠178,200,000，失败 | 1通过，0.00s；生产信念gold另1通过，0.01s |
| G70缺seed新case | 开局库存非零仍构造成功，失败 | 1通过，0.00s |
| G74两个预检case | 两入口失败后仍ready，均失败 | 2通过，0.14s |

没有运行回归、真实浏览器、长期市场、性能矩阵或发布验收；所有测试执行命令及case均不足10秒。
