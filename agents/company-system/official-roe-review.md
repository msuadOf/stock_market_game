## 复核要点

- 一般公式分母包含普通股股东归属期初净资产、普通股股东归属普通净利润的 `NP ÷ 2`，以及规则列示的权益增减月权重；普通与扣非 ROE 分别取对应利润作分子，共用普通净利润的半年度权重项。公式与规则9第4条一致。
- 期间以完整自然月计数并限制最多12个月。权益事项以实际生效日期定位，但按规则从发生次月开始计权，直至报告期末；发生月不计权重。期初资产、利润事实、报告身份和权益事件校验报告期间、`ScopeId` 与普通股股东归属口径；不完整权益事件历史明确拒绝计算。
- 法定利润事实及权益事件必须属于 `AttributableToOrdinaryShareholders`；`ConsolidatedIncludingMinorityInterest` 被拒绝。对应负例测试覆盖利润归属混配与报告身份总额口径。
- `BigInt` 保持精确中间值；测试覆盖 `i128::MAX` 事实不发生中间溢出。正利润且加权平均净资产非正时 ROE 不可用；零利润仅在加权平均净资产为正时报告为零。测试覆盖两类边界。
- 同一控制下企业合并与比较期间依规则第4条适用专门权重，当前 API 以 `DisclosureRoeUnsupported` 显式拒绝；不能用一般公式冒充这些特殊规则。报告尚未结束、期间/scope/归属不匹配、未来权益事项及不完整历史也均有显式拒绝路径。

## 限定

当前实现仅覆盖规则9第4条一般公式，明确不支持同一控制下企业合并及比较期间特殊处理。它没有证明或处理规则9第5至9条 EPS 特殊计算，也尚未接入公开披露报告生产者或消费者。规则9法源与适用日期详见 [official-roe-research.md](official-roe-research.md)；2026年修改/废止目录核验的边界亦以该研究记录为准。
