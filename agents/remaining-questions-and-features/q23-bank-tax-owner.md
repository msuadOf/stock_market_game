# Q23 Bank 所得税 owner

## 范围与依据

Bank 沿现行 `IncomeTaxPolicy` 的明确游戏简化使用年度评估链，不添加优惠税率、法定预缴日程或自动退税。官方依据与实际取证限制复用 [所得税研究](q23-tax-official-research.md)：年度纳税与财报周期分开；不得把所得税费用重复扣入税前利润；不声称完整 CAS 18 合规。

`BankBooks` 保存必填 `income_tax_policy` 与 `income_tax_position`，不提供旧格式默认、迁移或版本兼容。现有 Fixture 显式使用 2500bp 与五年结转，仅作为虚拟假设。

## 实施与验证清单

- 银行科目表和报告分类增加 `1811`、`222104`、`6801`，分别为递延所得税资产、当期所得税负债和所得税费用。借方 `222104` 沿统一报告投影列为 `CurrentTaxAssets`，不自动退款。
- `income_tax_owner` 与 `install_income_tax_owner` 为 crate 内原子更正组合提供严格输入和候选安装，不向 UI 暴露可任意修改的底层 owner。
- 年度重复处理、缴税不退款、必填存档字段、非法税资产基准和原始分录绕过存款子账分别由短测试验证；正式机制仍等待统一编译后的 runtime 红，再替换 stub。
- Bank 子账保护范围：`1131`、`1301`、`1303`、`2011`、`2601`、`2231`。原始更正不得绕过贷款／存款 owner；税科目由统一所得税 owner 处理。

当前记录是实施过程，不代表已通过最终短测或独立复核；实际日志与结论在取得结果后更新。
