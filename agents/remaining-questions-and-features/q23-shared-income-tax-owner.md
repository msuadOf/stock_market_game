# Q23 四行业共享所得税 Owner

## 范围与机制

`company::income_tax` 为四行业提供同一个年度评估纯机制，不复制四套亏损池与级联算法。
`IncomeTaxPosition` 保存年度期初亏损基准、连续评估链、开局真实递延所得税资产和历史
凭证有效期间。所有字段严格序列化，不添加 schema 代际、旧字段别名或恢复默认值。

`preview_tax_cascade` 只借用真实 `Books`、已有税状态、显式 `IncomeTaxPolicy` 与
下一事件身份，返回 `TaxCascadePreview`。它不修改任何输入；行业 Owner 使用既有
`post_with_commit` 原子过账成功后，才安装候选税状态。`IncomeTaxOutcome` 是四行业
共用的金额与处理结果，不用工业行业类型冒充其他行业 Owner。

所得税科目仍为 `1811`、`222104` 和 `6801`，行业科目表须显式包含这些科目。
税前利润排除 `6801`，不同公司使用各自亏损池，不能将集团税状态净额替代成员税状态。
历史差额的有效期间与真实实际凭证日期分开，年度重评不产生现金退款、补充现金或新的优惠税率。
税法与准则依据及简化范围沿用 [官方研究](q23-tax-official-research.md)，不将工程级联
宣称为完整税会差异、预缴、汇算清缴或退税程序。
