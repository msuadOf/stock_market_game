## 必须区分的事实

| 事实 | 核验依据及含义 | 不能混同的行为 |
|---|---|---|
| 销售与应收确认 | CAS 14 第四、五、十三条：履约、控制权转移，并满足合同确认条件；第五条含对价很可能收回，重大事实变化需重新评估 | 应收确认不是收到了现金；已明显不能收款的客户不能永久无条件赊销并冒充完全符合 CAS 14 |
| 账龄 | 开立日至观察日的时间，可用于风险分组 | 账龄不是逾期天数；未到期的长信用期不能算违约 |
| 信用恶化 | CAS 22 第五十二、五十三条：依据违约风险变化与合理前瞻信息评估，不只等逾期 | 信用恶化不是已经没付款，更不是股价跌就生成信用损失 |
| 逾期 | CAS 22 第五十三条：未按合同规定时间付款；超过30日通常显示风险显著增加，有合理证据可反驳 | 不是30日自动全额核销，也不是所有无重大融资成分应收都需在30日才转为整个存续期 ECL |
| 已发生信用减值 | CAS 22 第四十条列举重大财务困难、违约/逾期、异常让步、可能破产等可观察信息，可能共同作用 | 不能将暂时的信用冲击自动当实际全额损失 |
| ECL | CAS 22 第四十七、五十八至六十条：无偏概率加权、货币时间价值、合理信息；第四十七条明确即使预期全额收回、但晚于到期，也会产生信用损失 | 计提/转回是非现金，不是给公司发钱，也不是实际客户付款 |
| 简化法 | CAS 22 第六十三条：无重大融资成分等销售应收始终按整个存续期 ECL | 简化的是期间选择，不是准则规定“全部应收固定坏账率”或可忽略付款时间 |
| 部分实际回款 | 清偿实际收到的应收部分，剩余仍未结；CAS 14 的收入与履约事实不重复发生 | 不再次确认销售收入，不因一次部分回款清掉全部合同 |
| 核销 | CAS 22 第四十三条：不再合理预期全部或部分合同现金流量收回时减记账面余额，构成相关金融资产终止确认 | 核销不产生现金，不自动清除其他主体的法律付款义务，不是单纯冲击到期 |
| 核销后回收 | 后续实际收款需独立识别已核销部分与可回收余额，不能复用已清零应收当新销售 | CAS 22 第四十三条本身没有给出本项目科目级回收分录；现有银行处理器分录不能冒充该条逐字规定，工商新增分录需另行核验应用指南或明确处理选择 |

账龄分组、延付概率、回收率、客户支付资金规模、观察频率不是交易所统一规则；应作为可配置、可复现的虚拟行业参数，并明确“游戏假设”，不使用真实市场校准。技术重试也不能自动变成客户已支付的经济事实。

## 建议模型与已确认边界

用户于2026-10-05确认采用**轻量级有限现金模型**，不扩展为完整上市公司模拟系统。每个客户有独立现金余额、经营现金流和债务状态；普通客户共享统计化经营算法，不共享余额或债务；重要客户增加更细的独立参数与状态。统计模型仅生成明确来源和去向的经营收支，不直接抽签生成“偿债成功”。所有付款从实际可用现金支付，同一现金不能被多笔债务重复使用。

确认的生命周期包括正常付款、部分付款、逾期、后续补付、长期违约、部分或全部核销及核销后回收；核销不自动免除法律债务，回收不得重复记账。到期、现金不足和技术重试均不能触发补充客户资金。以下会计与工程建议必须遵守这个决定，具体经济参数仍需讨论，不把共享统计算法变成代表性客户或上市公司全量账套。

1. 每笔应收保留原合同到期日、已付、未结、逐笔核销及核销后已回收事实；实际延期不改写原到期日，正式展期另登记合同修改。清偿、核销、回收均以唯一业务事件幂等记账。
2. 到期调度只触发付款评估，不保证付款成功。允许全付、部分付、暂不付；未收残额进入后续收款计划，无现金时不能制造零金额收款凭证，也不能借重试自动补资金。
3. 信用状态按客户共享，冲击可影响该客户相关合同；应收残额和逾期属于逐合同事实，不因冲击结束清空。后续真实恢复付款能力可以部分或全额补付。
4. ECL 与真实付款计划分开：经营模拟生成实际付款结果，账务估计只依据当时已知信息，不读取未来随机结果。按合理概率情景估计金额和时间差；单独记录折现假设，不能把不折现包装成完整 CAS 22 计量。
5. 核销需明确无法合理收回的事实，不设统一“满几天自动全部坏账”；支持部分核销。核销后的真实回收有单独剩余限额，不能同时在普通应收和核销回收两路记两遍。
6. 模拟内公司间付款以同一 `TransferId` 原子扣付款方现金并增收款方现金，拒绝两边各自生成金额。所有客户均保留独立有限现金状态；与模拟外主体发生的经营收入／支出，也必须以明确、可追踪的现金流入／流出记入该状态，不得绕过余额直接生成偿债付款。证券玩家/NPC 的交易资金不参与公司客户兜底。
7. 会计事实与公开消息分开：公司账务在经营日真实发生，投资者按 Q11 的本人注意/获知规则反应，不把客户私有现金和未来回款安排提前暴露给全市场。

## 仍需讨论的经济参数

资金边界与模拟粒度已经确认，不再重复询问有限现金或外部付款计划二选一。尚未确认的是开局客户现金、经营净收支与债务规模的参数范围、重要客户识别及债务付款排序。经营收入必须明确属于哪种模拟内转账或模拟边界输入，经营支出同样记录去向；不能按应付缺口倒推收入，也不能从 NPC 股票账户取钱。具体默认值与分布不使用真实市场统计校准，须先讨论再实施。
