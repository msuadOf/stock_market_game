# 同花顺桌面层次复刻

2026-10-05 用户明确否定仅调整面板位置，要求电脑版游戏具有同花顺的操作层次。通过本机 CUA 阅读已打开同花顺的行情、自选双击个股和 F10 页面。未登录交易、未输入账户或提交真实委托。

- 行情：主区域密集列表，右侧选股预览；单击更新、双击深入。
- 个股：左侧窄股票列表、中央大图和指标、右侧报价与盘口、底部上下文入口。
- F10：左侧股票列表保留，中右区域为公司资料。
- 游戏适配：只展示引擎已有的分时、日K、量能/MACD/KDJ、盘口、公司财报、模拟委托；无广告、资讯推荐、真实指数或虚构指标。
- 规则与单位沿用现有数据层，本轮未调整交易制度；不新增法规实现依据。

第一版双布局预设已撤回。初版新导航曾附带自定义入口；独立复核发现重挂载会丢失局部状态，最终固定导航以稳定面板实例实现。旧 WorkspaceDesktopLayout 独立组件保留兼容测试，本轮不移除库依赖。此项以用户最新操作层次要求优先于 ADR-0007 原默认多面板描述，正式设计上下文与 UX 契约已同步。
