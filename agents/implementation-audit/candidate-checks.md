## 搜索补漏

主控另在 engine、Web、Server、Desktop 及脚本生产源码搜索 `todo!`、`unimplemented!`、TODO/FIXME、尚未实现/未实现、占位/不支持，排除测试和生成类型后逐项辨义。没有发现宏式空实现；“未实现盈亏/利润”是会计术语，不是 TODO。报表附注的其他综合收益/股东分配属于已声明简化；开局子账种子限制和占位结构注释不能单独证明后续行业模块缺失。真实非工商会话断点仍按 G36，不重复登记。

搜索仅用于补漏和反证，不能由“没有 TODO”推出代码全实现；全文追踪记录才是需求范围依据。

## 单独保留的短测覆盖建议

这些是测试代码/断言的补强建议，不混入未实现产品 G 清单；本轮没有写或运行这些用例。

- [S04](coverage/s04.md)：跨公司交错公开材料 ID 的成功获知、提前时点重复获知的错误优先级；批准时刻 08:00 另属游戏假设登记。
- [S12](coverage/s12.md)：成功收本的独立账务/本金断言、ECL 零差额返回与空批、贷款到期后续息、存款 365/366 日分类边界；同源确定性比较不替代这些独立期望。
- [R15](coverage/r15.md)：实际 step 中全成单撤单与重复撤单的计划反馈/原子性；盘前不允许撤单，不为补测试改变阶段规则。
- [R16](coverage/r16.md)：NPC 未受理符号报价跨内部 checkpoint/restore 的组合验证；受理订单不得恢复时重新定价，公共日终存档规则不变。
- [S18](coverage/s18.md)：已披露的嵌套 Rayon 协调者边界只做独立有限 deadline 验证，不能拿长时间挂起当普通单测。
- 其他代表性建议按各条记录及总账 §4 查阅；不是要求无差别增加重复测试或执行全回归。

## 不会据此扩大实施范围

- 不接真实市场数据、不补资金、不恢复公共日内存档、不自动强卖；最新 ADR-0023–0026 优先。
- 只把源码未完成且有现行有效承诺的部分列为 G；测试边界建议、历史运行证据不足、已批准未来/不支持分别记录。
- 不把“本分组没追到”当产品歧义；此类记录退回原分组继续查实际调用链。没有执行测试并不阻止静态定位，但不能因此宣称验收通过。
- 全文文档覆盖不是穷尽任意运行时 bug，也不是遍历所有 Git 修订。固定范围及排除项以 coverage-index 为准。
