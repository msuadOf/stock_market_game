## 新候选与歧义收口

- 新 G/Q 候选：0；相关既有问题留在 G16（年龄相关增长）、G39（K7 受理事实验证），其它公司/策略/存档问题按总台账现有 G/Q，不重复编号。
- 明确容量边界：server `MAX_SESSIONS=2` 是 ADR-0019 明确保留的局数政策；unbounded actor command channel 遵守移除固定命令条数门槛；broadcast 1024 缓冲只处理慢订阅者，不等同 command quota；解码 bytes/depth 是显式传输入口资源保护。
- ADR-0019 §2 中“存档保留已接收待处理请求”受较新 ADR-0025 限定：公共日级档不接受 pending player/NPC request 和活动订单；低层 engine 内存 checkpoint/验证存档仍可携带这些状态。两者的消费入口不同，不是语义矛盾。
- ADR-0004 对 RTK Query 的表述是潜在能力，不是必须接入的功能；Redux 仅存快照/界面视图，撮合仍由 engine 决定。未发现跨层语义漂移新候选。
- 原始历史复核 REJECT/旧corpus栈不可重验只保留为历史；本轮不推断测试、构建、GitHub CI 当前状态。普通 commit 不触发 CI 依据 ADR-0028。
