## 边界

删除历史按现有本地 Git refs 可达历史枚举；不是读取每个文件的每个提交版本，也不包含从未进入仓库的聊天/外部资料。原始 TXT/JSON/截图属于历史运行证据，按关联需要追查，不声称全部逐字阅读。全文文档覆盖与动态验收是两件事。
