## 新发现 / 歧义收口

### 总资产 API：延期已由等价生产实现承接，不登记缺口

- **核销**：已批准 spec §3 `docs/superpowers/specs/2026-06-29-account-design.md:65` 列出 `Account::total_assets(prices)`；更晚的 plan Self-Review `docs/superpowers/plans/2026-06-29-account.md:847,860` 明确本 plan 暂不实现，延期到顶层/market 聚合。检查当前生产代码后，等价能力由 `GameSession::account_equity` (`packages/engine/src/session.rs:1728–1744`) 与 `build_account_risk_observation` (`packages/engine/src/observation.rs:364–425`) 提供，不依赖同名 API。
- **最新政策覆盖**：ADR-0023 的合成历史与真实撮合政策、0024 的不补投资者资金、0025 的日终公共存档边界、0026 的个人机构风险规则均未取消净资产观察；0024 明确资金池不等于持仓市值。ADR-0018 整体 proposed，不能据此扩张为组合风险新需求。
- **生产路径→消费**：在账户与证券引用有效这一前提下，散户初始化/本人观察/计划仓位权重分别调用账户权益；机构计划观察用同一语义按已固定行情视图计算，随后调用机构账户风险逻辑。通用风险观测器同时输出账户 equity、回报、回撤和各持仓市值，并将其可报告的金额计算错误经 `Result` 传递。`GameSession::account_equity` 对持仓证券引用使用 `unwrap_or_else(panic!(...))`：未知证券是内部 invariant panic，不是 `Result` 错误；金额算术溢出则返回 `MoneyError`。源码见 `packages/engine/src/session.rs:1728–1744,1766–1797,1868–1900`、`packages/engine/src/session/decision_chain.rs:718–778,1198–1224`、`packages/engine/src/observation.rs:364–425`。
- **分类 / 验证**：已实现（由上层承担），仅保留旧 API 名称/归属未随 plan 同步的文档差异；不需要新短测或新编号。既有 session、observation、experience 测试源码是证据入口，本轮未运行。

### 本批歧义 / 已被替代项

- Spec §3 将 `market_value` 描述成 `Option`，plan Task 7 草案对溢出曾 `unwrap_or(Money::ZERO)`；现行实现返回 `Result<Option<Money>, MoneyError>`（`packages/engine/src/account.rs:502–529`），显式传播错误，符合工程原则，不是缺口。
- Spec 要求 `Account`/`Position` serde（§7第11项）；ADR-0025 要求公共加载只接受完整日终档，当前显式持久化投影保留继续运行事实。因此账户对象无 serde derive 不构成缺失；应以日终恢复验收，而非重新要求日内完整快照。
- Spec `apply_trade` 直接消费单个 `Trade` 的签名与 plan 的 `(price, qty)` 签名均非当前生产调用契约；成交回执汇总→`apply_settlement` 是实际适配方式，须保留累计费用/原子性语义，不以旧方法名未被调用报缺。
- 交易费率/市场真实校准、持续成交、外部补钱、每日持久化均不在此条账户需求的现行必做范围；不据旧设计稿示例覆盖更新决定或交易规则登记。
