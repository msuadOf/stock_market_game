### 持久化链路图（实际生产边界）

`market tick / CivilUpdate` → `ProtocolSession` 完成整日结并捕获 keyed `SaveSlot` → Server/Tauri/Web host 按 `seq + settledDate` 取不可变候选 → Web 校验日终边界 → `DayEndPersistence` 串行化且校验 generation → 浏览器 quick slot / 已授权文件 target → UI 成功/失败 notice。

内部 `ProtocolCheckpoint` 的 `clone_for_tick_shadow` 用于宿主批次失败回滚，不调用保存文件 API；`GameSession::save()` 是引擎快照投影入口，不等于公共保存 API。公共 `ProtocolSession::save()` 只返回最近日终档，且首次日结前拒绝；`save_candidate(key)` 只取对应 CivilUpdate 候选。不得因测试、verification harness 或内存 checkpoint 可序列化而称“日内公共存档已实现”。
