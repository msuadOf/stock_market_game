## 新发现与歧义收口

### §6 不支持合同的可达边界补核

- **无产品会话/API入口：** `BankProductKind` 与 `InsuranceProductKind` 未出现在 SessionSetup、session protocol、Web/server/Tauri 输入；`operations/bank.rs:55-81` 固定构造 TermDeposit/TermLoan，`operations/insurance.rs:42-59` 固定构造 TermProtection。它们是 engine Rust 行业构造 API 的入参，不是玩家可提交的公司配置。因而本发布没有把这些合同暴露为可交互输入。
- **银行可达且 typed reject：** `company/bank/mod.rs:56-66,69-88` 定义 StructuredDerivative/FvtplInstrument/FvociInstrument；`bank/deposits.rs:143-154` 与 `bank/lending.rs:21-32` 在业务校验前分别调用 `require_deposit`/`require_loan`。`tests/bank_accounting/failures/contracts.rs:12-55` 对结构化、FVTPL、FVOCI拒绝并断言状态不变。无独立投资/衍生工具 API；这些类别通过现有存款/贷款入口传入会拒绝，不能据此声称已支持相应合同交易。
- **保险可达且 typed reject：** `company/insurance/mod.rs:61-84` 定义 Participating、UnitLinked、ReinsuranceCeded、ReinsuranceAccepted；`insurance/premium.rs:62-73` 的 `establish_group` 首先 `require_supported`。`tests/insurance_accounting/failures/unsupported.rs:13-64` 逐类断言 `UnsupportedContract` 且账套不变。
- **恢复边界：** BankBooks/InsuranceBooks 是 serde 类型，但存档的 deposit/loan/group 子账结构不保存 `BankProductKind`/`InsuranceProductKind`；Web精确 schema `apps/web/src/save/schema/company/books/bank.ts:6-`、`insurance.ts:6-` 也不含产品种类。因此恢复路径不存在“从存档还原 unsupported kind 再拒绝”的语义；不能写成恢复时会逐类拒绝。手改存档的其他业务状态校验不等同合同类型校验。
- **只有政策/不可表达的类别：** CAS 25 PAA/VFA 在 `company-accounting.md:226-229` 和 fixture `policy-sources.json:650-653` 声明不支持，但当前 `InsuranceProductKind` 没有计量方法字段或 PAA/VFA 枚举；没有可提交此类模式的构造输入，未来扩展才需要 typed reject。套期同样无产品类型入口。CAS 17 等官方原文取证债仍按文档，不升级成合规证明。
- 结论：不能再把“§6每项都从会话/API输入一路拒绝”当验收结论；现有保险/银行直接 engine API 拒绝有逐类源码测试，session层未暴露；计量方法类仅为明确政策范围。若后续把相关输入加入 session/API，再新增入口级拒绝测试。无新增 G/Q 编号。

- **新 G/Q：0。** 本组确认的未接/部分项均已在总表登记：G06–G09（估值/个人信息与经历链）、G28（固定集团边界）、G35（工商期末）、G36（自定义行业完整会话接线）、G38（预算分类）；Q02/Q03/Q11分别覆盖读取经历、RegulationProfile冻结映射、直接重估触发。未因存在类型、模块、cfg(test) helper 或孤立测试而另报实现。
- **明确不做：** 公司行为 §1–4 当前股东结算、除权除息、股本事件、股东税和现金补充；会计 §6所列合同/计量类别。ADR-0024已取消“资金池必须循环”的要求，但未取消本次不执行股东结算的边界。
- **法源待证不是实现漏项：** 会计矩阵及 §7 标出的 CAS 原文/税法/交易所季报规则阻塞继续作为证据债；本轮未联网核验、未把版本化简化说成法规合规。
- **验收债：** 上表列出的已有测试仅是源码存在证据，本轮未运行。建议后续以短 fixture 验证从公开报告发布→查询消费、个体读取→决策、各不支持合同真实入口显式拒绝；范围不扩到真实市场历史校准（ADR-0023明确禁止该校准承诺）。
