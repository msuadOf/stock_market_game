## 历史记录核销与候选

- 指定三篇均为 ADR 模板/决策正文，没有 task execution log、失败/通过回执或未完成审阅清单；不能从背景、alternatives 或 consequences里的“后续需要”伪造历史测试债。
- `0000-template.md` 的占位字段是填表说明；`0001` 的 accepted-only-append 是治理规则，工作树无法证明 Git 历史是否曾改写；该证据边界不是代码缺口。
- `0002` 核心同一 Rust engine 的生产消费已追到 WASM worker、Server actor与Tauri actor。WASM使用JS值映射并不违反语言无关数据契约；不以“没有 JSON字符串”为名新建候选。真实三宿主 parity/restore/release验收仍沿既有 R20 与 G01–G05/G18–G20范围登记。
- 现行决定检查：ADR-0005保留核心单引擎并细化宿主；ADR-0019限定当前单局范围；ADR-0023至0026更新合成历史、资金、日终存档与个体机构风险；ADR-0027/0028更新部署和CI触发边界。无一推翻Rust engine核心路线。大A语义、费用、T+1、撮合规则仍以现行交易规则及相关ADR为准，本轮不评价其规则正确性。
