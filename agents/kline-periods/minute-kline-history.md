# 分钟 K 历史消费

历史分钟 K 面板使用公开 `queryMarketHistory` 查询已日结自然日期，按返回的真实分钟 OHLCV 生成 120／60／30／15／5／1 分钟柱。连续竞价上午、下午分别从 09:30、13:00 锚定；开盘和收盘集合竞价独立成柱。聚合保留真实稀疏性，不为无成交分钟补柱；成交股数与成交笔数按 u64 十进制字符串精确相加，成交额按 u128 十进制分字符串精确相加。组件另提供独立 `queryCurrentMinuteHistory` 属性来消费 Core 的实时分钟查询，按返回的分钟 bar 聚合，并显示真实观察时刻及形成中桶；不从 `NotEnded`、日 K 或 `PricePoint` 推造 OHLC。

组件入口为 `apps/web/src/components/MinuteKlinePanel.tsx`，纯聚合函数为 `apps/web/src/components/minute-kline.ts`。日期历史和当前日实时分钟使用分开的 Host 查询，`tickRefreshKey` 控制实时刷新；`scopeKey`、证券或日期变化后会丢弃过期响应。Host 方法、类型生成和图表父组件接线仍由对应任务完成，本记录只覆盖这个独立消费者。

独立代码审查发现 Core 允许连续竞价分钟 `690` 和 `900`，分别表示上午／下午连续成交收口边界；聚合现已将它们钳制进本半日最后分钟桶，活动观察位于午休、`11:30` 或 `15:00` 时不标记形成中桶。聚合入口验证有效自然日、正规范 u64 股数／笔数、u128 成交额以及累加上界；成交额复用 `parseTurnoverCents`，u64 复用 `parseDecimalId`，价格复用 `parseMoney` 并核验 OHLC 和成交额范围。分钟历史日期严格递增、不接受重复日。活动查询严格要求证券、live 标记和日期与当前上下文一致，日期切换丢弃迟到响应；响应为空时 UI 不生成图形或数据行，失败不遗留其他自然日数据。

分钟图复用 `KlineCoordinatePlot` 的价格和成交量坐标结构、分钟时间轴与现有 `candleBodyPrices`／`candleWickPrices` 语义；上涨柱为红色空心实体、影线分成实体上下两段，下跌柱为绿色实心实体，成交量显示真实股数并跟随涨跌空心／实心样式。高精度股数缩放只在 SVG 绘图坐标中按比例近似，数据与坐标标签仍由 BigInt 精确生成。

第二轮图表审查修正了极值精度：价格涨跌方向使用原始分字符串的 BigInt 比较，避免 i64 大额仅差一分时被 JS `Number` 舍入成相等；u64 最大股数比例图若向下取整为 0 像素，则正成交量至少显示 1 像素，最大柱仍为 62 像素。KlineCoordinatePlot 仅绘制价格／成交量网格，本组件在共用同一横坐标后另显 `HH:mm` 分钟轴标签，不调用日 K 的日期格式器。

修复后定向 Node 单测 16/16 通过，外部 10 秒 deadline，命令约 0.77 秒。包含周期映射、午休隔离、Core 端点、u64/u128 overflow、有效日期、错误输入、重复日期、live 迟到请求、错误、错日期、空 bars、蜡烛图颜色／影线／成交量坐标和最大 u64 极小柱。当前项目级 TypeScript 检查仍受共享 `engine-host.ts` 冲突影响；Host 父级 selector 接线属于父任务。
