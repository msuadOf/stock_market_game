# WASM memory 终局错误页修复证据（2026-11-02）

## 范围与语义核对

- worktree：`.worktree/wasm-terminal-fix-20261102`
- branch：`codex/wasm-terminal-fix-20261102`
- base：`main` / `0f40ffbc2dfd11db3e8ac72faa23ac3643b699b9`
- `main` 的 `HostFailure` 只要求 `code`、`where`、`message`，`recoverable` 与 `recoveryActions` 可选；`WasmMemoryStorageError` 与 `WasmDocumentMemoryError` 都能以结构化字段进入 App 的 error 分支。
- `WasmDocumentMemoryOwner` 用 `terminal` 锁存 `fail(...)` 后的错误，`WasmMemoryStorage` 也会用 `gate` 锁存 `MEMORY_HANDOVER_CORRUPT`；当前 document 不能继续分配游戏实例。
- `MEMORY_RESIDUAL_EXHAUSTED` 表示保守残留预算耗尽；`MEMORY_HANDOVER_CORRUPT` 表示残留账或交接记录无法安全读回。刷新同一标签页不会清除 `sessionStorage` 中的残留链/记录，因此不提供刷新、创建新局、选择其他日终存档或返回启动选择作为恢复动作。
- 用户可执行动作：关闭当前标签页，再在全新标签页手动打开原网址；不要使用浏览器恢复或复制标签页（可能连同 `sessionStorage` 继承原 residual chain）。复制错误反馈。仅自然日日结成功后更新存档，未保存的日内进度会丢失。
