# Learnings

## 2026-09-13

- `apps/desktop/src-tauri` is the Tauri project directory and Cargo package `stock-market-game`; its Tauri config invokes `pnpm --filter web build` and consumes `apps/web/dist`.
- The untracked `apps/web/wasm-pkg` output must be generated by the existing platform WASM scripts before a clean frontend/Tauri package build can succeed.
- Current Tauri v2 documentation supports native Linux, macOS, and Windows bundles. Linux/macOS to Windows is a constrained NSIS route with `cargo-xwin`; it is not an MSI, signing, or general cross-platform bundle route.
- Preflight validates only concrete local artifacts and executable availability. Native OS dependencies, version compatibility, MSI WiX/VBScript, signing, notarization, and frontend compilation remain Tauri/Cargo or platform-tooling responsibilities and must be presented as deferred.
- 2026-09-13 remediation: argument-free LLVM availability probes now treat a successfully spawned `lld-link` or `llvm-rc` as available regardless of exit status; explicit status checks remain on version/status-contract commands.
