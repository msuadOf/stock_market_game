Engine 核心必须无字符串化：运行时数据结构里不允许 String 存在。

**Why:** 用户 2026-10-06 明确："我的目标是要让 Engine 里面无字符串化"（从股票代号数值化扩大到全部）。动机：字符串是测得的主要 CPU 成本（分配 14.75%+比较搬运 9.4%），且数值 id 让配置化、通信减负、核心简化。早期阶段允许破坏性修改存档/wire 契约，不写兼容层。

**How to apply:** 所有标识（股票/账户/订单/信封/NPC）一律数值 id，类别用 enum；引擎错误用错误码 enum+数值上下文（结构化），显示文本只在边界格式化，首错测试按结构比较；字符串只准出现在边界（配置加载映射、显示/日志格式化、serde 序列化文本）。新代码评审时把"引擎里出现 String"当违规项。相关：[[engine-perf-1000x]] [[no-versions]]
