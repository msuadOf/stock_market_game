需要用户做决策时，不许只给方案选项或概念描述让用户选——必须先在独立工作区把性能实验做了，拿到具体数字，把数据摆出来让用户结合数据判断。

**Why:** 用户 2026-10-08 明确："你不要一个空的就让我决策，你有需要让我决策的部分的时候，你先去开一个工作区，把性能实验做了，看看性能提升多少，告诉我数据，让我结合着数据做判断。"空口问决策把判断负担推给了用户，而 agent 有能力先拿数据降低决策成本。

**How to apply:** ①识别到"需要用户拍板"的分叉点时，先问自己"能不能先做实验拿数据"——如果能，先做再问；②汇报格式：`方案A实测+X%，方案B实测−Y%，建议Z因为...`，不是"要不要做A还是B？"；③如果实验成本极高（>2小时），可以先给初步数据+后续计划；④实验做完不许停——负结果按 [[verify-before-reject]] 循环继续，正结果报告数据请用户确认后落地。相关：[[verify-before-reject]] [[negative-result-attribution]] [[collaboration-mode]]
