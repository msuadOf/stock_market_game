正式基准的核选择规则：测前检查各核占用，选**基线占用 <10%** 的 16 核段跑；不要求其他 agent 全部停止。由此引入的误差（用户估计最多 ~10%）可以接受——目标是 1000x，测出 900x 也算基本达成。

**Why:** 用户 2026-10-06 修正此前"全机必须安静"的规则：为测速停掉所有并行工作代价太高，而 10% 以内的误差不影响大局（1000 差 10% 也才 900，能达到 900 差不多达到目的）。

**How to apply:** 基准前用 /proc/stat 或类似手段量候选核段占用（含避开繁忙核的 SMT 兄弟段），<10% 才用；每跑记录占用协变量；判定协议保留（锚定 + 交错配对 + 区间分离），锚定漂移作废阈值可放宽到 ~5%，实验保留门槛维持 ≥2% 且符号一致。相关：[[engine-perf-1000x]]
